# 数学二 110 分专题教程页设计

## 目标

把现有 `kaoyan-math2-110.html` 从单页总纲扩展为与 408 学习页一致的专题教程体系。目标读者以数学二 110 分为目标，需要明确知道哪些内容必学、会考什么、要练到什么程度，以及标准题如何一步步求解。

## 页面结构

保留现有总纲作为入口，新增八张专题页，共九页：

1. 数学二 110 分总纲
2. 函数、极限与连续
3. 一元函数微分学
4. 一元函数积分学
5. 多元函数微积分与二重积分
6. 常微分方程
7. 行列式与矩阵
8. 向量组与线性方程组
9. 特征值、相似与二次型

## 每页固定模块

- 章节定位、经验分值、题型与建议学习时间。
- 七列学习决策矩阵：知识点、优先级、要不要学、考频、经验分值、考察题型、学到什么程度。
- 方法选择顺序或识别流程。
- A 类知识点的原理、完整教程例题、逐步解法、结果检查和易错点。
- B 类知识点的标准题或短场景。
- C 类知识点的定义、识别方式和不深挖理由。
- 考试型练习、答案与本章达标清单。
- 上一章、下一章互链。

## 视觉规范

- 沿用知识页的浅色/深色主题、Inter 与 IBM Plex Mono 字体。
- 数学页使用紫色作为章节主色，优先级和考频使用语义色。
- 优先级标签：A 红色、B 蓝色、C 灰色。
- 考频标签：极高红色；高和中高橙色；中蓝色；低灰色。
- 决策矩阵使用圆角外框和行分隔线；移动端只允许表格容器内部横向滚动。
- 公式、方法树、积分区域和线代流程使用内嵌 SVG 或 CSS，不依赖远程图片。

## 内容深度

- A 类：至少一题完整教程例题；同一能力不堆同质题。
- B 类：讲到能完成标准题；只有常见计算考法才给完整计算。
- C 类：不配置长例题，只说明条件、公式和跳过边界。
- 例题每一步必须说明依据；不能用“显然”“整理可得”跳过陌生推理。
- 分值和考频均标注为经验区间，不伪造精确概率、年份或题号。

## 110 分策略

- 总纲继续采用客观题 65 分底盘、解答题约 45 分的目标模型。
- 各专题明确 A/B/C 学习边界和低收益题型。
- 训练目标高于正式目标，为计算失误留缓冲。
- 考纲外内容只在总纲集中列出，不在专题页扩展。

## 验收标准

- 九页均可从首页进入，专题页前后互链。
- 每页矩阵列名、标签颜色和移动端行为一致。
- 所有导航锚点有效，无页面级横向溢出和控制台错误。
- A 类核心计算题包含规则来源、具体数字、关键中间值、结果验证和易错点。
- 不覆盖或提交项目中无关的并行改动。
