# 408 计算机网络：数据链路层考点全解页面设计

## 目标

在现有“物理层考点全解”之后新增一篇完整的数据链路层学习页，面向 408 考研复习。页面应同时满足三件事：

1. 按考纲形成完整知识主线，适合首次学习与系统复盘。
2. 突出计算题、协议对比和高频易错点，适合考前查漏。
3. 围绕 408 总分 110 分目标明确学习优先级，指出低性价比内容。
4. 延续现有知识页的视觉、主题和交互规范，并在首页提供入口。

## 产物范围

- 新增页面：`doc/kaoyan-408-network-datalink.html`
- 修改首页：`index.html`
  - 在现有“408计网 · 物理层考点全解”附近增加数据链路层入口。
  - 同步维护页面中静态链接和搜索数据两处入口。
- 不修改共享主题文件，也不重构其他文章。

## 页面结构

页面按 408 考纲顺序组织：

1. 数据链路层总览
2. 基本功能与组帧
3. 差错控制
   - 奇偶校验
   - CRC
   - 海明码
4. 流量控制与可靠传输
   - 停止-等待协议
   - 后退 N 帧（GBN）
   - 选择重传（SR）
   - 滑动窗口、序号范围和信道利用率
5. 介质访问控制
   - 信道划分
   - ALOHA
   - CSMA
   - CSMA/CD
   - CSMA/CA
6. 局域网与以太网
   - MAC 地址
   - 以太网帧
   - 最短帧长
   - VLAN 与 802.1Q
   - 无线局域网必要考点
7. 广域网协议
   - PPP
8. 数据链路层设备
   - 网桥
   - 二层交换机
   - MAC 地址表自学习与转发
   - 冲突域和广播域
9. 速记与易错点
10. 典型题练习

每个核心概念分别说明“是什么、做什么、关键约束”，不把多个术语堆进同一段。公式和协议必须配具体数字例子。

## 题型、分值与 110 分目标

页面总览先交代全卷定位：

- 408 满分 150 分，其中计算机网络约 25 分；全卷为 40 道单选题共 80 分、综合应用题共 70 分。
- 数据链路层没有官方固定分值。页面只给基于历年真题形态的经验区间，不伪造精确概率：通常会以 1～3 道选择题出现，约 2～6 分；也可能与时延、吞吐量或网络层地址规划合并成综合题的一问，此时相关分值可能更高。
- 题型集中在概念辨析、协议状态判断和公式计算。2025 真题曾把 GBN 窗口、序号位数与卫星链路利用率放进网络综合题，说明滑动窗口不能只按“小选择题”准备。
- 110/150 约为 73% 得分率。对应策略不是完整掌握所有教材细节，而是拿稳公式固定、边界清楚、能重复训练的分数；对冷门协议史和标准字段死记硬背降级处理。

页面为各考点增加三级标签：

- **A 必学**：CRC、海明码基本计算、停止-等待/GBN/SR、窗口与序号范围、信道利用率、CSMA/CD、最短帧长、以太网帧、交换机自学习、冲突域/广播域。这些内容可出计算题或稳定的辨析题，且会与其他章节组合。
- **B 会辨析即可**：组帧方法、复用方式、ALOHA/CSMA 各变体、CSMA/CA、VLAN、802.11 基本机制、PPP。掌握定义、核心差异和典型场景，不深挖实现。
- **C 低性价比**：令牌传递的细枝末节、各 IEEE 子标准编号、MAC 帧前导码逐位背诵、PPP 每个状态/字段、教材扩展出的 HDLC 细节。页面明确标为“时间紧可跳过”，其中不在现行考纲明列的 HDLC 不作为正文学习章节。

“考的概率”统一使用“高频 / 中频 / 低频”与经验分值区间表达，并注明命题会跨层组合、单年波动很大，不能把历史频次当作下一年概率。

## 图解设计

使用内嵌 SVG，而非外部图片或位图。这样可随屏幕缩放、适配深浅主题，并避免资源路径失效。

计划包含四张必要图解：

1. **滑动窗口图**：区分已确认、已发送未确认、可发送、暂不可发送四种序号状态，并对比 GBN 与 SR 的接收窗口。
2. **CSMA/CD 时序图**：展示最远两站传播、冲突发生、冲突信号返回和发送方完成检测的 `2τ` 过程。
3. **以太网帧格式图**：按字段宽度展示目的地址、源地址、类型、数据和 FCS，并标出 64～1518 字节范围。
4. **交换机自学习图**：展示交换机如何根据源 MAC 学习端口，再依据目的 MAC 执行转发、过滤或泛洪。

图解必须有文字替代说明，移动端允许横向滚动或自然换行，不依赖颜色作为唯一信息提示。

## 关键计算与例题

至少覆盖：

- CRC 余数与发送码字
- 海明码监督位数量
- 停止-等待协议信道利用率
- GBN/SR 窗口与序号位数关系
- 滑动窗口最大信道利用率
- CSMA/CD 最短帧长
- 交换机 MAC 表学习与转发判断
- 冲突域、广播域数量判断

例题解答按真实运算步骤编号，配套提醒不占步骤编号。
