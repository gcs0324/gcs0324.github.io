# 408 计算机网络：数据链路层考点全解页面设计

## 目标

在现有“物理层考点全解”之后新增一篇完整的数据链路层学习页，面向 408 考研复习。页面应同时满足三件事：

1. 按考纲形成完整知识主线，适合首次学习与系统复盘。
2. 突出计算题、协议对比和高频易错点，适合考前查漏。
3. 延续现有知识页的视觉、主题和交互规范，并在首页提供入口。

## 产物范围

- 新增页面：`doc/kaoyan-408-network-datalink.html`
- 修改首页：`index.html`
  - 在现有“408计网 · 物理层考点全解”附近增加数据链路层入口。
  - 同步维护页面中静态链接和搜索数据两处入口。
- 不修改共享主题文件，也不重构其他文章。

## 页面结构

页面按 408 考纲顺序组织：

1. 数据链路层总览
2. 基本功能与组帧
3. 差错控制
   - 奇偶校验
   - CRC
   - 海明码
4. 流量控制与可靠传输
   - 停止-等待协议
   - 后退 N 帧（GBN）
   - 选择重传（SR）
   - 滑动窗口、序号范围和信道利用率
5. 介质访问控制
   - 信道划分
   - ALOHA
   - CSMA
   - CSMA/CD
   - CSMA/CA
6. 局域网与以太网
   - MAC 地址
   - 以太网帧
   - 最短帧长
   - VLAN 与 802.1Q
   - 无线局域网必要考点
7. 广域网协议
   - PPP
   - HDLC
8. 数据链路层设备
   - 网桥
   - 二层交换机
   - MAC 地址表自学习与转发
   - 冲突域和广播域
9. 速记与易错点
10. 典型题练习

每个核心概念分别说明“是什么、做什么、关键约束”，不把多个术语堆进同一段。公式和协议必须配具体数字例子。

## 图解设计

使用内嵌 SVG，而非外部图片或位图。这样可随屏幕缩放、适配深浅主题，并避免资源路径失效。

计划包含四张必要图解：

1. **滑动窗口图**：区分已确认、已发送未确认、可发送、暂不可发送四种序号状态，并对比 GBN 与 SR 的接收窗口。
2. **CSMA/CD 时序图**：展示最远两站传播、冲突发生、冲突信号返回和发送方完成检测的 `2τ` 过程。
3. **以太网帧格式图**：按字段宽度展示目的地址、源地址、类型、数据和 FCS，并标出 64～1518 字节范围。
4. **交换机自学习图**：展示交换机如何根据源 MAC 学习端口，再依据目的 MAC 执行转发、过滤或泛洪。

图解必须有文字替代说明，移动端允许横向滚动或自然换行，不依赖颜色作为唯一信息提示。

## 关键计算与例题

- 海明码监督位数量
