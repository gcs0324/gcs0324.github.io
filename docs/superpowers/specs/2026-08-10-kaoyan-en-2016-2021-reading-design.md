# 英语二 2016—2021 阅读真题页面设计

## 目标

在现有 2012—2015 英语二阅读页基础上，新增 2016、2017、2018、2019、2020、2021 六个独立年份页面，方便按年份逐套精读。新增页面保持当前站点的阅读体验、信息密度和移动端适配，不引入汇总页或新的交互体系。

## 页面与入口

新增以下文件：

- `doc/kaoyan-en-2016-reading.html`
- `doc/kaoyan-en-2017-reading.html`
- `doc/kaoyan-en-2018-reading.html`
- `doc/kaoyan-en-2019-reading.html`
- `doc/kaoyan-en-2020-reading.html`
- `doc/kaoyan-en-2021-reading.html`

每个页面包含该年英语二阅读理解 Part A 的 Text 1—4。首页 `index.html` 的可见侧栏与脚本卡片数据各增加六个入口，顺序紧接 2015 年页面，保证两处导航一致。

## 内容结构

每个年份页沿用 2012—2015 页的结构：

1. 页头：年份、英语二阅读真题标题和内容说明。
2. 固定导航：Text 1—4 的页内锚点。
3. 每篇阅读：主题、难度、约数与建议时间。
4. 完整英文文章，按原始段落排版。
5. 核心词汇表：筛选影响理解或具有复用价值的词组，给出简明中文释义。
6. 折叠题目：保留题号、题干和 A—D 选项。
7. 折叠答案：按题号给出正确选项。

不沿用旧页中“本周精读”“已完成”等带个人进度的临时标记，六个新页面保持中性的真题资料定位。

## 视觉与实现

- 复用 `../shared/theme.css` 和同步加载的 `../shared/theme.js`，支持现有明暗主题切换。
- 保持 Inter、IBM Plex Mono、卡片、标签、折叠题目和 900px 正文宽度等既有视觉规范。
- HTML、CSS 均为页面内静态内容，不增加构建工具、依赖或网络接口。
- 保留现有移动端断点；窄屏下缩小页边距和文章卡片内边距。
- 所有锚点和折叠组件均使用原生 HTML，页面关闭脚本后正文和题目仍可阅读。

## 内容准确性

- 年份、Text 顺序、21—40 题号、选项和答案必须与对应年份一致。
- 不凭印象补写题目或答案；发现来源冲突时，以能够交叉核对的版本为准。
- 主题、难度、约数、建议时间属于学习辅助信息，不伪装成官方标注。
- 核心词汇释义结合文章语境编写，避免只给不适用于本文的常见义。

## 验收标准

- 六个文件均存在，且各含 Text 1—4、20 道题和 20 个答案。
- 页面标题、年份、题号、页内锚点互相一致，无从模板残留的旧年份或旧内容。
- 首页两处入口均覆盖 2012—2021，链接目标存在且顺序一致。
- HTML 基础结构完整，无重复 ID、未闭合的主要标签或明显乱码。
- 用本地静态服务抽查桌面端和移动端：主题、导航、折叠题目、滚动锚点可用。
- 检查 Git 差异只包含六个新页面、首页入口和本设计说明；不提交、不推送，除非用户另行确认。

## 范围外

- 不创建 2012—2021 汇总页。
- 不增加翻译、新题型、完形填空或作文内容。
- 不改写 2012—2015 页面，也不重构共享样式。
- 不自动提交或推送 Git 变更。
