# 408 操作系统 110 分学习页面实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 6 个面向 408 目标 110/150 的操作系统教程页，并补齐计网决策标签与首页入口。

**Architecture:** 每页是独立静态 HTML，共用 `shared/theme.css` 和 `shared/theme.js`，用章首知识点决策矩阵统一表达 A/B/C、考频、分值、题型和掌握程度。A 类计算与流程题在对应页内给出可独立复现的逐步例题；6 页通过前后章链接串联。

**Tech Stack:** HTML5、页内 CSS、内联 SVG、原生主题脚本，无构建工具。

## Global Constraints

- 遵循 `WRITING.md`：A 类例题不得跳步，B 类只到会辨析，C 类不配长例题。
- 考频仅使用极高/高/中/低，不伪造精确概率；章分值使用经验区间并声明可波动。
- 每页必须使用 `../shared/theme.css` 和同步加载的 `../shared/theme.js`。
- 不改动本任务范围外的文件，特别是同时出现的英语二设计文件。
- 手机端正文不得整页横向溢出；表格和 SVG 可在自己的容器内滚动。
