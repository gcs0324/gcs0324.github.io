# 数学二 110 分备考总纲 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增并发布一份按现行题型设计的数学二 110 分学习目录和得分路线。

**Architecture:** 新建独立静态页面 `doc/kaoyan-math2-110.html`，使用共享主题并内联页面组件样式；首页在考研备考分类新增入口。旧综合计划保留，避免无关科目目标被连带修改。

**Tech Stack:** HTML、CSS、原生 JavaScript、`shared/theme.css`、`shared/theme.js`。

## Global Constraints

- 使用 10 道选择题、6 道填空题、6 道解答题的现行结构。
- 每个知识点必须同时给出重要度、掌握程度、考频、常见分值和题型。
- 考频只用定性分档，分值只写历史常见区间并提示单年波动。
- 110 分预算为选择 40、填空 25、解答 45。
- 数二考纲外内容才可直接跳过；考纲内低频内容最多降为 B/C，不写成绝对不考。
- 同步提交用户指定的 `长难句拆解提示词.md`。
