# 英语二 2016—2021 阅读真题页面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 2016—2021 六个英语二阅读真题独立页面，并更新首页两处入口。

**Architecture:** 每个年份使用一个自包含静态 HTML 页面，复用共享主题文件和 2012—2015 页的组件结构。一个只读校验脚本检查文件、年份、题号、答案、锚点和首页链接，浏览器抽查负责视觉与交互验收。

**Tech Stack:** HTML5、CSS、原生 `details`、共享 `theme.css` / `theme.js`、shell/Python 只读校验。

## Global Constraints

- 不改写 2012—2015 页面，不重构共享样式。
- 每年包含 Text 1—4、题号 21—40 与对应答案。
- 首页可见侧栏与脚本卡片数据两处入口保持一致。
- 不提交、不推送，除非用户另行确认。
