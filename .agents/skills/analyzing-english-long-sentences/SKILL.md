# 英语长难句拆解

## 目标

把英语复杂句还原成可检查的语法结构，同时给出自然中文和便于理解的英文简化句。分析必须建立在原句证据上；无法仅凭单句确定的指代或语义应明确标注不确定性，不得臆造上下文。

## 执行方式

1. 完整阅读待分析句；若用户提供多个句子，逐句独立输出。
2. 分析每句前，读取 [输出契约](references/output-contract.md)。
3. 严格按其中五个输出板块生成内容，随后执行自查；自查是内部质量门，不默认展示。
4. 用户明确要求简版、只翻译或只分析某一语法点时，服从用户指定范围，不强制输出全部板块。

## 核心要求

- 先找主句主干，再处理从句、并列、修饰和附注，保持结构层级。
- 每个编号块先说明整块的句法身份、块间关系和整句作用，再给翻译并拆解内部成分。
- 从句必须标明类型并拆出内部主谓宾或主系表。
- 括号、破折号、冒号说明、同位语和独立结构单独成块。
- 省略结构先给还原句，再指出省略位置、内容和语法作用。
- 每个并列分句说明主语是明示、重复、省略还是共享。
- 逐一解释 it、this、that、they 等指代；证据不足时提供候选并说明原因。
- 语法链必须保留原文，不用“主语”“宾语从句”等标签替换原词。
- 翻译以准确理解为先，不机械维持英文词序。

## 交付前检查

确认所有实词都进入分析、各层修饰对象明确、特殊标点功能已解释、语法链可还原原句，并且简化句没有改变核心含义。
