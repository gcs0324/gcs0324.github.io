从机器学习到大语言模型

一条清晰的学习路径 — 只保留必要的知识
① 机器学习 → ② 神经网络 → ③ LLM
① 机器学习
让计算机从数据中自动学习规律，而非靠人工编写规则。

监督学习

数据带标签。模型学习输入→输出的映射关系。
例：给图片标注"猫/狗"，训练分类器。

无监督学习

数据无标签。模型自行发现数据内部结构。
例：将用户按行为聚类成不同群体。

强化学习

智能体在环境中行动，通过奖惩信号学习策略。
例：围棋AI通过胜负反馈优化走法。

核心范式

训练：用数据调整模型参数
推理：用训练好的模型对新数据做预测
整个过程 = 找一个函数，使预测尽量接近真实值

关键术语

特征 (Feature) 数据的可度量属性，如房屋面积、图片像素值
标签 (Label) 监督学习中的目标值，如房价、类别名
损失函数 衡量预测与真实值的差距，训练的目标就是最小化它
梯度下降 沿损失函数的梯度反方向逐步更新参数，使损失收敛
过拟合 / 欠拟合 过拟合：模型死记数据，泛化差；欠拟合：模型太简单，学不到位
为什么学 ML：神经网络和 LLM 都是机器学习的子领域。理解"数据→模型→训练→推理"这一范式，是后续所有知识的基石。
② 神经网络
一种由"神经元"层层堆叠的机器学习模型，能自动提取数据的深层特征。

单个神经元

神经元

计算 y = f(w·x + b)
w 权重控制每个输入的重要程度
b 偏置是阈值偏移
f 激活函数引入非线性

激活函数

没有激活函数，多层网络 = 一个线性变换，毫无意义。
常用：ReLU（max(0,x)，简单高效）
旧式：Sigmoid（挤压到0~1）

网络结构

输入层：接收原始特征
隐藏层：逐层提取更高阶特征
输出层：给出最终预测
层数越多 → 表达能力越强 → "深度学习"

前向 & 反向传播

前向：数据从输入→输出逐层计算
反向：从输出→输入逐层计算梯度
梯度 = 每个参数对损失的影响程度
反向传播是训练的核心算法

① 前向传播 → ② 计算损失 → ③ 反向传播 → ④ 更新参数 → 循环直到收敛

关键术语

学习率 每步参数更新的幅度，太大震荡、太慢收敛
批量 (Batch) 每次更新使用的一小批样本，兼顾效率与稳定性
Epoch 遍历全部训练数据一次，训练通常需数十到数百个 epoch
参数量 模型中所有权重+偏置的总数，决定模型容量
为什么学神经网络：LLM 本质上是一个超大规模的神经网络（Transformer）。理解前向/反向传播、激活函数、参数训练，才能理解 LLM 是怎么"学"的。
③ 大语言模型 (LLM)
以 Transformer 为架构、以海量文本为燃料的超大规模神经网络，能理解和生成自然语言。

Transformer 核心架构

自注意力机制

Transformer 的灵魂。每个 token 生成三个向量：
Q（查询）、K（键）、V（值）
注意力 = softmax(Q·Kᵀ) · V
效果：每个词"看到"整段话，决定关注谁

位置编码

自注意力本身没有顺序概念。
位置编码给每个 token 注入位置信息，
让模型区分"猫吃鱼"和"鱼吃猫"。

Token化

文本 → token序列 → 数字ID → 嵌入向量
token 可以是词、子词或字符
常用方案：BPE（字节对编码）

生成式推理

LLM 逐 token 生成：
每次基于已有上下文预测下一个 token
采样策略决定多样性和质量
（贪心 / top-k / top-p / 温度）

LLM 训练三阶段

预训练

在万亿级 token 上做"下一个 token 预测"。这是自监督学习——不需要人工标注，文本本身就是标签。模型由此获得语言知识和世界知识。

微调 (SFT)

用人工编写的"指令-回答"数据继续训练。让模型从"续写文本"变为"按指令回答问题"。数据量小但质量高。

对齐 (RLHF)

人类给模型输出打分，训练一个奖励模型，再用强化学习优化 LLM 使其输出更符合人类偏好（安全、诚实、有帮助）。

涌现能力

参数规模超过一定阈值后，模型突然展现出小模型不具备的能力（推理、编程、数学等）。目前尚无完整理论解释。

关键术语

上下文窗口 模型一次能处理的 token 数，决定"记忆长度"（如 4K/8K/128K）
参数量 模型权重总数，7B = 70亿，175B = GPT-3规模，直接决定能力和成本
Temperature 控制采样随机性。低=确定/枯燥，高=多样/不可控，0=贪心
Top-p / Top-k 只从概率最高的前 k 个或累积概率前 p 的 token 中采样，过滤低质量选项
In-context Learning 在提示词中给出示例，模型无需更新参数即可适应新任务（GPT-3 核心能力）

主流 LLM 架构对比

知识链总结：机器学习建立了"数据→模型→训练→推理"范式 → 神经网络用层层堆叠的神经元实现特征自动提取 → Transformer 架构用自注意力突破序列长度瓶颈 → 在超大规模数据和参数下训练，诞生了能理解与生成语言的大语言模型。
