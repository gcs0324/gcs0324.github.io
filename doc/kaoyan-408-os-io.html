§1 四种 I/O 控制方式：关键是“谁搬、何时通知”
方式CPU 等待方式数据搬运者中断粒度适用理解
程序直接控制（查询）循环检查状态，忙等CPU 指令在设备寄存器与内存间搬通常不用中断简单但浪费 CPU
中断驱动发命令后运行别的进程CPU 执行中断服务程序搬数据常按字/字节或较小单位消除持续忙等，但频繁中断
DMACPU 只初始化 DMA 参数DMA 控制器在设备与内存间成块搬运通常一块完成后中断大批量高速传输
通道CPU 启动通道程序专门 I/O 处理器控制多台设备任务或通道程序完成后进一步减轻 CPU 管理负担
易错

DMA 不是“完全不用 CPU”：CPU 仍需设置内存起址、字节数、方向并处理完成中断；DMA 减少的是逐字搬运和中断次数。

教程例题 · 判断 I/O 方式而不是背名称
某设备每得到 1 B 数据就中断 CPU，由中断服务程序把数据寄存器内容写入内存。另一设备由 CPU 设置内存首址和 4 KiB 长度，传完才中断。各是什么方式？
1先看谁实际搬数据。第一台设备的每个字节都由 CPU 执行中断程序搬入内存，所以是中断驱动 I/O。
2第二台设备只由 CPU 设置参数，4 KiB 在设备与内存之间成块搬运，完成后一次中断，符合 DMA。
3验证：若是查询方式，CPU 会持续读状态位；题中第一台虽频繁进入 CPU，但 CPU 可在两次中断间做其他工作，不是忙等。
第一台：中断驱动；第二台：DMA。判据是搬运主体与中断粒度。
§2 I/O 软件层次：请求向下，完成通知向上

设备独立性

应用使用逻辑设备名和统一接口，不依赖某型号寄存器。逻辑设备表把逻辑名映射到物理设备及其驱动入口。

驱动程序

属于内核 I/O 子系统，直接了解控制器命令和状态。设备无关层不应包含某品牌寄存器的操作细节。

§3 缓冲：先画时间线，再套公式

单缓冲

设备输入下一块时，CPU 可处理上一块；但缓冲区正在被某一方使用时，另一方不能覆盖或读取它。

双缓冲

两个缓冲交替使用，可让设备和 CPU 更充分并行。是否完全重叠仍取决于各阶段时间。

缓冲池

用多块缓冲和空/满队列服务多个进程或设备，重点理解生产者—消费者关系。

教程例题 · 单缓冲处理 4 个数据块
假设设备把一块数据输入缓冲需 T=100 ms，CPU 从该缓冲处理一块需 C=60 ms；忽略传送到用户区等额外时间。单缓冲处理 4 块共多久？无重叠又多久？
1第 1 块必须先输入，花 100 ms；随后 CPU 处理第 1 块的 60 ms 可与设备输入第 2 块的前 60 ms 重叠。
2因为输入较慢，稳态每推进一块由 max(T,C)=100 ms 决定。前 3 次推进后，第 4 块输入完成。
3最后一块没有后续输入可与它重叠，还要补一次 CPU 处理 60 ms。因此总时间 T+(n-1)max(T,C)+C。
4代入 n=4：100+3×100+60=460 ms。若设备输入和 CPU 处理完全串行，则 4×(100+60)=640 ms。
单缓冲且满足题设重叠条件：460 ms；无重叠：640 ms。公式必须服从题目的缓冲占用规则。
§4 设备分配与 SPOOLing
类型含义典型理解
独占设备一段时间只分配给一个进程打印机直接独占会让进程长期等待
共享设备多个进程可交替访问磁盘可按请求调度共享
虚拟设备用快速共享设备模拟慢速独占设备的并发使用SPOOLing 将打印输出先放磁盘输出井，再由守护进程送打印机
SPOOL

输入井/输出井在磁盘上，不等同于内存缓冲区；SPOOLing 提高独占设备利用率并提供虚拟设备效果，但物理打印机同一时刻仍只能执行有限的实际作业。

§5 磁盘调度：方向与是否到边界决定答案
算法选择规则优点风险/易错
FCFS按到达顺序公平、简单总寻道可能很大
SSTF选离当前磁头最近的请求平均寻道较小远端请求可能饥饿
SCAN沿当前方向服务，到端点后反向等待较均匀题目可能规定“到物理端点”或“到最远请求”
C-SCAN只沿一个方向服务，到端点后回另一端等待时间更均匀回卷距离通常也计入磁头移动
教程例题 · 四种磁盘调度逐步计算
磁道 0～199，请求队列按到达顺序为 98、183、37、122、14、124、65、67，磁头初始在 53，SCAN/C-SCAN 初始向磁道号增大方向。按“SCAN 到 199 后反向、服务完最后请求即停止”求总移动磁道数。
1FCFS 路径：53→98→183→37→122→14→124→65→67。总移动 =45+85+146+85+108+110+59+2=640。
2SSTF 每次重选最近请求：53→65→67→37→14→98→122→124→183。总移动 =12+2+30+23+84+24+2+59=236。
3SCAN 先向上：53→65→67→98→122→124→183→199，再反向服务 37→14。总移动 =12+2+31+24+2+59+16+162+23=331。
4C-SCAN 只向上服务：53→65→67→98→122→124→183→199→0→14→37。总移动 =12+2+31+24+2+59+16+199+14+23=382。
5检查：SSTF 最小并不代表无缺点；SCAN/C-SCAN 的结果依赖初始方向、是否必须到端点以及回卷是否计数，考试必须按题设写路径。
FCFS 640；SSTF 236；SCAN 331；C-SCAN 382（仅适用于题设给定的边界规则）。
§6 SSD 与机械磁盘不要套同一模型

机械磁盘 HDD

访问时间常拆为寻道时间、旋转延迟和传输时间。磁盘调度主要优化机械磁头移动。

固态硬盘 SSD

没有机械磁头和旋转延迟；闪存通常按页读写、按更大的块擦除，控制器通过 FTL 做地址映射、垃圾回收和磨损均衡。

边界

408 目标 110 分不需要深挖 SSD 固件算法。掌握“无寻道、写前擦除、擦除粒度更大、磨损均衡由控制器完成”等选择题结论即可。

考试型练习 · DMA 中断次数
一次 DMA 传送 8 KiB，每个数据块 1 KiB；DMA 每传完一块中断一次。忽略异常，共产生多少次完成中断？如果改为中断驱动且每传 1 B 中断一次呢？
1DMA 按 1 KiB 块通知，块数 = 8 KiB / 1 KiB = 8，因此 8 次完成中断。
2中断驱动按 1 B 通知，8 KiB = 8×1024 B，因此 8192 次中断。
DMA：8 次；逐字节中断驱动：8192 次。题目改变“中断粒度”时必须重新计算。
