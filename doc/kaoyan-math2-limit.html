§1 方法选择主线
先代入判型→乘除结构先化简→局部等价或 Taylor→仍不定再洛必达→数列考虑夹逼/单调有界
常用展开：sin x=x-x³/6+o(x³)；ln(1+x)=x-x²/2+o(x²)；eˣ=1+x+x²/2+o(x²)
原则

先写适用条件和第一步，再计算。方法不满足条件时，即使最后数字碰巧正确也不算真正掌握。

识别信号直接代入出现 0/0、∞/∞、1^∞ 等不定式，或式子中存在明显抵消、振荡结构。

代数化简

因式分解、有理化、通分后能消掉致零因子时优先。

0/0 → 先化简
等价无穷小

适合乘除的整体因子；加减发生抵消时不能局部替换。

sin x ~ x
Taylor 展开

加减抵消或需要比较高阶无穷小时，展开到首个非零项。

eˣ=1+x+x²/2+o(x²)
洛必达法则

只用于满足条件的 0/0 或 ∞/∞；幂指型先取对数。

分子、分母分别求导
1

第一步：直接代入并判型

先代入趋近点。若得到有限确定值就结束；若得到 0/0、∞/∞、0·∞、∞-∞、1^∞ 等不定式，先记录类型再变形。

2

第二步：先做代数化简

乘除式先找公共因子、共轭式或可通分结构。很多题在这一步就能消掉致零因子，不需要上来求导。

3

第三步：按结构选择工具

乘除因子可考虑等价无穷小；加减抵消用 Taylor；仍为 0/0 或 ∞/∞ 才检查洛必达条件；振荡与数列结构另看夹逼或单调有界。

4

第四步：保留首个非零阶并反查

最终结果由分子、分母的首个非零项决定。比较阶数、符号和数量级；条件允许时用另一种方法复算一次。

完整例题

计算 lim[x→0](eˣ-1-x)/x²

1

直接代入得到 0/0；分子是三个量相减，1 和 x 会抵消，不能只用 eˣ-1~x。

2

展开到分母需要的二阶：

eˣ = 1+x+x²/2+o(x²)
3

代回并消去低阶项：

eˣ-1-x = x²/2+o(x²)
4

同除以 x² 后取极限：

(eˣ-1-x)/x² = 1/2+o(1) → 1/2
结果为 1/2。反查：连续使用两次洛必达，也得到 eˣ/2 在 x=0 处的值 1/2。

结果检查比较分子、分母的阶数和最终数量级；条件允许时换一种方法反查。

易错点未判型直接洛必达；在加减式中局部等价替换；Taylor 展开阶数不够。

考试速记先代入判型 → 先化简 → 加减看 Taylor → 0/0、∞/∞ 再考虑洛必达

间断点五步判定

目标找出函数在哪些点不连续，并准确判断间断点属于哪一种类型。

1找可疑点
→
2算左右极限
→
3比较函数值
→
4判断类型
1

第一步：找可疑点

先从定义域和函数结构中找“可能断开”的位置。优先检查：

  • 分母为 0 的点
  • 对数真数为 0 或负数的边界
  • 偶次根号内等于 0 的边界
  • 分段函数的分界点
  • tan x、cot x 等函数的无定义点
2

第二步：计算左右极限

对每个可疑点 x₀，必须从左、右两侧分别靠近。分段函数尤其不能只算一个整体极限。

limx→x₀⁻ f(x)
limx→x₀⁺ f(x)
3

第三步：判断连续性

函数在 x₀ 连续，下面三个条件必须同时成立，少一个都不行：

f(x₀) 有定义　＋　limx→x₀f(x) 存在　＋　limx→x₀f(x)=f(x₀)

结果检查左右极限相等只能说明极限存在，还必须继续与函数值比较。

4

第四步：判断间断点类型

先看左右极限是否有限、是否相等，再判断能否通过补一个函数值把断点接上。

可去间断点

左右极限存在且相等，但函数值不存在或不等于这个极限。

跳跃间断点

左右极限都存在且有限，但两个数不相等。

无穷间断点

至少一个单侧极限为 +∞ 或 -∞。

振荡间断点

至少一个单侧极限持续振荡，无法趋近一个确定值。

完整例题

判断 f(x)=(x²-1)/(x-1) 的间断点及类型

1

分母在 x=1 时为 0，所以 x=1 是可疑点。原函数在这里没有定义。

2

当 x≠1 时，x²-1=(x-1)(x+1)，因此可以先约去 x-1。

limx→1 (x²-1)/(x-1) = limx→1(x+1) = 2
3

左右极限都等于 2，但 f(1) 不存在。只要补定义 f(1)=2，函数就能连续。

结论：x=1 是可去间断点。

易错点不能看到“函数无定义”就直接写可去间断；类型由单侧极限决定。无穷大也不表示极限作为有限数存在。

考试速记找可疑点 → 算左右极限 → 比较函数值 → 判断间断类型
§3 典型题怎么一步步做
教程例题 · Taylor 为什么要展开到二阶
求 lim[x→0](ln(1+x)-x)/x²。
1直接代入是 0/0；分母为二阶量，因此分子至少展开到 x²。
2ln(1+x)=x-x²/2+o(x²)，减去 x 后为 -x²/2+o(x²)。
3同除 x² 得 -1/2+o(1)，极限为 -1/2；也可两次洛必达反查。
-1/2；检查结果为有限常数，与分子分母同阶一致。
教程例题 · 等价无穷小不能拆加减
求 lim[x→0](sin x-x)/x³。
1sin x~x 只能用于整体乘除；若直接把 sin x 换成 x，分子会错误变成 0。
2展开 sin x=x-x³/6+o(x³)，所以 sin x-x=-x³/6+o(x³)。
3除以 x³ 得 -1/6+o(1)。
-1/6；易错点是对加减式逐项使用一阶等价。
教程例题 · 递推数列先证明再求值
a₁=1，aₙ₊₁=√(2+aₙ)，求极限。
1由 a₁<2，若 aₙ<2，则 aₙ₊₁<2，归纳得上界 2。
2aₙ₊₁≥aₙ 等价于 2+aₙ≥aₙ²；在 1≤aₙ<2 时成立，所以单调递增。
3单调有界故收敛。令极限 L，得 L=√(2+L)，结合 L≥0 解得 L=2。
L=2；不能一开始只解极限方程而不证明收敛。
教程例题 · 分段点连续参数
f(x)=(eˣ-1)/x（x≠0），f(0)=a，求连续时 a。
1只需检查 x=0，因为其他点由初等函数连续性保证。
2lim[x→0](eˣ-1)/x=1，可由重要极限或一阶展开得到。
3连续要求极限等于函数值 f(0)=a，因此 a=1。
a=1；同时左右极限均为 1。
考试型练习 · 考试型练习
判断 x=0 是 f(x)=1/(1+e^(1/x)) 的哪类间断点。
1x→0⁺ 时 1/x→+∞，极限为 0；x→0⁻ 时 1/x→-∞，极限为 1。
2左右极限都存在但不相等，因此是跳跃间断点。
第一类跳跃间断点；不是无穷间断点。
