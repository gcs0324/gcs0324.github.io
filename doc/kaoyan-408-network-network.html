§1 IPv4 数据报与地址

网络层做什么 B 会辨析

链路层只负责一跳；网络层根据目的 IP 选择下一跳，把数据报从源主机送到目的主机。IP 提供无连接、尽最大努力服务：不保证到达、不保证按序，也不自动重传。

IP 地址标识接口 A 必学

IPv4 是 32 位。路由器每个接口连接不同网络，通常各有一个 IP；一台多网卡主机也可有多个 IP。不能简单说“一个设备只有一个 IP”。

首部字段为什么要有常见考法
首部长度 IHLIPv4 首部可变长，IHL 单位是 4 BIHL=5 表示 20 B
总长度标明首部+数据的完整字节数最大 65 535 B
标识/DF/MF/片偏移支持分片和目的端重组片偏移单位 8 B；DF=1 禁止分片
TTL每过一个路由器减 1，防止环路永久存在减到 0 丢弃并触发 ICMP 时间超过
协议告诉目的主机交给哪个上层TCP=6，UDP=17，ICMP=1
首部校验和只检查 IPv4 首部每跳 TTL 改变，因此路由器重算

特殊地址 A 必学

  • 主机位全 0：网络地址，不能分给普通主机。
  • 主机位全 1：该子网定向广播地址，不能分给普通主机。
  • 127.0.0.0/8：环回；255.255.255.255：受限广播。
  • 私有地址：10/8、172.16/12、192.168/16，通常借助 NAT 访问公网。
§2 IPv4 分片
每片最大数据长度 = floor((MTU - 首部长度) ÷ 8) × 8

为什么要除以 8 再取整？片偏移字段以 8 B 为单位，所以除最后一片外，每片数据长度必须是 8 的整数倍。总长度字段按字节计；片偏移按 8 B 计，不能混用。

教程例题 · 分片逐步计算
IPv4 数据报总长 4 000 B，首部 20 B，经过 MTU=1 500 B 的链路。求每片总长、MF 和片偏移。
1原数据长度 = 4 000-20 = 3 980 B。每片还要带自己的 20 B 首部。
2一片最多装 1 500-20=1 480 B 数据；1 480÷8=185，恰好整除，所以前两片各装 1 480 B。
3剩余数据 = 3 980-2×1 480=1 020 B，第三片总长 1 020+20=1 040 B。
4偏移量按原数据中的起点除以 8：第一片 0；第二片 1 480÷8=185；第三片 2 960÷8=370。
5前两片后面还有分片，所以 MF=1；最后一片 MF=0。所有片的标识字段相同，目的主机才能识别它们来自同一数据报。
总长：1500、1500、1040 B；偏移：0、185、370；MF：1、1、0。数据和=3980 B，反向检查一致
§3 子网划分、CIDR 与路由聚合
网络地址 = IP AND 子网掩码　　地址数 = 2主机位数

前缀 /p 表示左侧 p 位固定为网络前缀，剩余 32-p 位可变化。普通子网可用主机数通常为 2^(32-p)-2，减掉网络地址和广播地址；点到点等特殊场景以题意为准。

教程例题 · VLSM 子网划分
单位得到 192.168.10.0/24，按从大到小为 100、50、20 台主机分配三个互不重叠子网，要求尽量节省地址。
1先给最大需求分配，避免小块切碎空间。100 台需满足 2^h-2≥100，h=7，可用 126 台，所以前缀 /25。分配 192.168.10.0/25，可用 .1～.126，广播 .127。
250 台需 h=6，得到 /26。紧接上一块从 .128 开始，分配 192.168.10.128/26，范围 .128～.191，可用 .129～.190。
320 台需 h=5，得到 /27。下一块从 .192 开始，分配 192.168.10.192/27，范围 .192～.223，可用 .193～.222。
4剩余 192.168.10.224/27 可留作扩展。各块起点都是块大小的整数倍：128、64、32，边界合法且不重叠。
100台：.0/25；50台：.128/26；20台：.192/27；剩余 .224/27
教程例题 · 路由聚合为什么看共同前缀
聚合 35.230.32.0/21、35.230.40.0/21、35.230.48.0/21、35.230.56.0/21。
1前两段 35.230 相同，只比较第三字节：32=00100000，40=00101000，48=00110000，56=00111000。
2四者第三字节最左侧共同的是 001 三位；加前两字节 16 位，共同前缀长 19 位。
3共同前缀后全部补 0，第三字节仍为 00100000=32，所以聚合地址是 35.230.32.0/19。
答案：35.230.32.0/19；检查：/19 覆盖第三字节 32～63，正好包住四个 /21
§4 最长前缀匹配与逐跳转发
教程例题 · 最长前缀匹配
路由表有 132.0.0.0/8→R1、132.0.0.0/11→R2、132.19.232.0/22→R3、默认路由→R4。目的地址为 132.19.237.5，走哪条？
1/8 只要求第一字节为 132，匹配。
2/11 还检查第二字节前三位。19=00010011，前三位 000，与该前缀匹配。
3/22 的块大小在第三字节为 4；232/4 的范围是 232～235，而目的第三字节为 237，所以不匹配。
4多条匹配时选前缀最长、范围最具体的 /11，因此发给 R2；默认路由仅在没有更具体匹配时使用。
答案：R2。不是按表项书写顺序，也不是选数值看起来最接近的网络地址
教程例题 · ARP 到底查询谁
A 与 B 不同子网，中间经过路由器 R。A 第一次向 B 发送数据，缓存均为空。每一跳如何确定 MAC？
1A 用自己的 IP 与掩码判断 B 不在本子网，因此不能直接 ARP 查询 B；A 的下一跳是默认网关 R 的左接口。
2A 广播 ARP 请求“谁是 R1 的 IP”，R 左接口单播响应 MAC R1。第一跳帧的目的 MAC 是 MAC R1，而 IP 数据报目的地址仍是 IP B。
3R 收到帧后去掉帧头，TTL 减 1并查路由表。若 B 在 R 直连网络，R 从右接口广播 ARP 查询 IP B，获得 MAC B。
4R 重新封装第二跳帧：源 MAC=MAC R2，目的 MAC=MAC B；源/目的 IP 仍为 IP A/IP B。若还有下一个路由器，ARP 查询的是下一个路由器接口，而不是最终 B。
核心：IP 标识端到端，MAC 只服务当前一跳；ARP 永远解析“当前链路上的下一跳 IP”
§5 NAT、DHCP、ARP 与 ICMP
机制解决什么问题必会边界
ARP同一链路上把下一跳 IPv4 地址解析为 MAC请求广播、响应通常单播；不跨路由器广播
DHCP动态获得 IP、掩码、网关、DNS应用层、基于 UDP；Discover/Offer/Request/ACK
ICMP报告 IP 交付异常和网络诊断Ping 用回送；Traceroute 利用 TTL 与时间超过
NAT/NAPT私网地址共享公网地址转换 IP；NAPT 还转换端口，破坏纯端到端透明性
易错

DHCP 虽然配置的是网络层参数，却是应用层协议；ARP 的分层在不同教材表述可能不同，408 做题重点是它完成 IP 到 MAC 的映射及广播范围。

§6 路由算法与协议
协议范围/算法交换什么110 分掌握程度
RIPAS 内；距离向量周期性向邻居发送整张距离向量；跳数最多 15B：会更新表，知道慢收敛和“好消息快、坏消息慢”
OSPFAS 内；链路状态洪泛链路状态，掌握拓扑后用 DijkstraB：会与 RIP 对比，不手算复杂 LSA
BGPAS 之间；路径向量可达前缀和 AS 路径，策略优先B：知道 eBGP/iBGP 与非单纯最短
C 类取舍

移动 IP、IGMP/PIM、多协议标签交换和 SDN 控制器内部细节只需知道用途。对 110 分目标，投入时间远不如把子网、转发和 TCP 做熟。

§7 IPv6 B 会辨析

和 IPv4 的核心差异

  • 地址 128 位；基本首部固定 40 B。
  • 路由器不分片，只能由源主机处理分片。
  • 取消首部校验和，选项移入扩展首部。
  • 没有广播，使用单播、多播和任播。

地址压缩

每组前导 0 可省略；连续全 0 组可用一次 :: 代替。一个地址只能出现一次 ::，否则无法判断省略了多少组。

过渡主要认识双栈与隧道，不必背全部扩展首部编号。

§8 速记、易错与练习

网络层拿分清单

  • 片偏移单位 8 B；IPv4 重组只在目的主机。
  • 主机数先求 h，再取 /（32-h）；VLSM 从大到小分。
  • 聚合看共同前缀；转发选最长匹配。
  • IP 端到端基本不变，MAC 每跳改变；ARP 找下一跳。
  • TTL 每过路由器减 1；Ping/Traceroute 都和 ICMP 有关。
  • RIP 距离向量，OSPF 链路状态，BGP 路径向量。
考试型练习 · 综合判断
主机地址 180.80.77.55/22，求网络地址、广播地址与可用范围。
1/22 的掩码第三字节为 11111100=252，块大小 256-252=4。
2第三字节 77 落在 76～79 块，因为 floor(77/4)×4=76。
3网络地址把主机位清 0：180.80.76.0；广播地址把主机位置 1：180.80.79.255。
4普通主机可用范围去掉两端：180.80.76.1～180.80.79.254。
网络 180.80.76.0/22；广播 180.80.79.255；可用 .76.1～.79.254
