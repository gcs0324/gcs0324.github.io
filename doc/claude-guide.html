01 核心概念
Claude 是什么

Claude 是 Anthropic 开发的大语言模型，以长上下文窗口（最高 200K tokens）、强推理能力和安全对齐著称。相比 GPT 系列，Claude 在长文档理解、代码生成和遵循复杂指令方面表现更稳定。

模型系列对比
模型定位上下文适用场景
claude-haiku-3.5速度优先200K实时问答、分类、摘要
claude-sonnet-4.5均衡（默认）200K日常开发、写作、分析
claude-opus-4.5推理最强200K复杂推理、研究、架构设计
选型原则：80% 的任务用 Sonnet；需要多步推理、思维链时升级 Opus；追求速度/低成本用 Haiku。
Token 与上下文窗口
  • ▸ 1 个 token ≈ 0.75 个英文单词 ≈ 0.5 个汉字
  • ▸ 200K tokens ≈ 约 15 万个汉字 ≈ 一本 400 页技术书
  • ▸ 超长上下文时，Claude 对开头和结尾注意力最强，中间容易被稀释
  • ▸ 关键指令放在 System Prompt 和用户消息末尾，重要内容别只放中间
02 提示词技巧
🎯
给 Claude 一个角色
开头用 你是一名资深 Java 后端工程师，精通 Spring Boot 和微服务架构，让模型进入专业模式，回答更聚焦。
🧩
思维链（Chain of Thought）
在问题后加 请一步一步思考 或 先分析再给出结论，可大幅提升复杂推理准确率。Opus 会自动开启扩展思维链。
📋
Few-shot 示例
提供 2-3 个输入/输出示例让模型理解格式。格式化输出（JSON、Markdown 表格）时效果尤佳。
🔪
任务分解
复杂任务拆成子任务逐步完成，比一次性要求所有内容质量更高。可告知 Claude 先给我大纲，我确认后你再展开每节。
📐
格式约束
明确要求输出格式：用 Markdown 表格、以 JSON 返回，字段包含 name/desc/example。Claude 遵循格式指令很稳定。
🔄
迭代优化
不满意时追问 这个解释太笼统，举一个 Java 代码示例 或 从面试官角度补充 2 个追问点，比重新提问效率更高。
System Prompt 最佳结构
# 角色
你是 [具体角色]

# 背景
[项目/任务上下文]

# 规则
- 回答用中文，代码用英文注释
- 关键结论用粗体标注

[期望的格式描述]
03 Claude.ai 功能
Projects 推荐
  • ▸ 创建 Project 后可共享 System Prompt 给该项目所有对话
  • ▸ 上传文档到 Project Knowledge（代码库、PRD、架构图）
  • ▸ 同项目的多轮对话共享上下文记忆
  • ▸ 适合：持续迭代的项目、团队共享的知识库
文件上传
  • ▸ 支持 PDF、Word、代码文件、图片
  • ▸ 上传代码仓库（ZIP）让 Claude 全局理解项目
  • ▸ 上传截图描述 UI 问题比文字描述更准确
  • ▸ 单次最大 10 个文件，每个文件 ≤ 10MB
Artifacts（工件）
  • ▸ Claude 生成的代码/HTML/SVG 会显示在独立预览面板
  • ▸ 可直接运行 React 组件和 HTML 页面
  • ▸ 追问时 Artifact 自动增量更新，无需复制粘贴
Memory 新功能
  • ▸ Claude 可跨对话记住用户偏好和背景
  • ▸ 说 记住我是 Java 开发，偏好简洁回答 即可
  • ▸ 设置 → Memory 可查看/删除记忆条目
04 Claude Code CLI
安装与启动
npm install -g @anthropic-ai/claude-code   # 安装
claude                                       # 启动交互模式
claude "解释这段代码的作用"                   # 单次问答
claude --print "生成 README"                 # 输出到终端（不交互）
--effort 推理力度 常用
--effort low
快速回答，少思考
适合：改命名、查语法、简单问答
--effort medium（默认）
平衡速度与质量
适合：日常开发、Code Review
--effort high
最大推理力度，多步反思
适合：复杂重构、难 Bug、架构设计
常用 Slash 命令
/help查看所有可用命令
/clear清除当前对话上下文，开始新会话
/compact压缩对话历史，节省 token（保留要点）
/review对当前工作目录的代码变更进行 Code Review
/init分析当前项目，生成 CLAUDE.md 项目说明文件
/memory查看并编辑 Claude 记住的用户信息
/permissions查看 Claude Code 当前的工具权限配置
/cost查看本次会话消耗的 token 和费用估算
MCP（模型上下文协议）

MCP 允许 Claude Code 调用外部工具和服务，扩展能力边界。

# 在 ~/.claude/settings.json 中配置 MCP 服务器
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_TOKEN": "your_token" }
    }
  }
}
常用 MCP：filesystem（文件读写）、github（PR/Issues）、puppeteer（网页截图）、postgres（数据库查询）
CLAUDE.md —— 项目上下文文件

在项目根目录放 CLAUDE.md，Claude Code 启动时自动读取，作为持久化的系统提示。

# Project Overview
Spring Boot 电商系统，Java 17，MySQL 8 + Redis 7

## 代码规范
- Service 层用 @Transactional，不在 Controller 层开事务
- 统一异常用 GlobalExceptionHandler，不要裸 try-catch
- 字段校验用 @Valid + DTO，不直接用 Entity 接收参数

## 禁止操作
- 不直接 DROP TABLE
- 不修改 migration 历史文件
Hooks —— 自动化工作流

在 ~/.claude/settings.json 配置 hooks，在 Claude 执行特定操作前/后触发脚本。

{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Bash",
      "hooks": [{"type": "command", "command": "echo 'Claude is about to run bash'"}]
    }],
    "PostToolUse": [{
      "matcher": "Edit",
      "hooks": [{"type": "command", "command": "npx prettier --write $CLAUDE_FILE_PATH"}]
    }]
  }
}
常见用途：保存前自动格式化、修改代码后运行测试、记录操作日志
05 API 集成
Java SDK 基础调用
// Maven: com.anthropic:sdk:0.x.x
AnthropicClient client = AnthropicOkHttpClient.builder()
    .apiKey(System.getenv("ANTHROPIC_API_KEY"))
    .build();

Message message = client.messages().create(
    MessageCreateParams.builder()
        .model(Model.CLAUDE_SONNET_4_5)
        .maxTokens(1024)
        .addUserMessage("用一句话解释 JVM 类加载机制")
        .build()
);
System.out.println(message.content().get(0));
Python 流式输出
import anthropic
client = anthropic.Anthropic()
with client.messages.stream(
    model="claude-sonnet-4-5",
    max_tokens=1024,
    messages=[{"role":"user",
      "content":"解释 HashMap 扩容"}]
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)

07 最佳实践与注意事项
⚠️ 幻觉（Hallucination）：Claude 可能自信地给出错误信息，特别是具体版本号、API 签名、统计数据。重要技术决策要交叉验证官方文档。
✅
给 Claude 足够上下文
不要只说"帮我优化代码"，要说"这是 Spring Boot 项目，该方法每秒被调用 1000 次，目前 P99 延迟 500ms，帮我优化"。
✅
让 Claude 先反问再回答
在提示词末尾加 如果需要更多信息来给出更好的答案，请先问我，能大幅减少因信息不足导致的质量下降。
✅
用 XML 标签分隔不同内容
Claude 对 XML 标签识别非常好：<code>[代码]</code>、<requirements>[需求]</requirements>，比用换行分隔更清晰。
✅
Claude Code：善用 /compact 控制 token
长对话后用 /compact 压缩上下文，节省 token 同时保留关键进度。上下文窗口到 80% 时 Claude 会自动提醒。
⚠️
敏感信息不要输入
API Key、数据库密码、用户隐私数据不要直接粘贴。Claude Code 默认不上传文件内容，但养成习惯：脱敏后再分析。
⚠️
代码生成后必须 Review
Claude Code 写的代码可能引入不必要的依赖、忽略边界情况或使用过时 API。生产环境代码务必人工 Review 后再合入。
