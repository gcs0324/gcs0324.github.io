1.1 七种不定式 约1.5h▼
🎯 目标分值： 4-5分 选择/填空必考
📘 核心定义 当 x→x₀（或 x→∞）时，若 f(x) 和 g(x) 的极限无法直接确定，称为不定式。共七种类型，解题思路统一为"识别→转化→求解"三步法。
类型识别特征转化策略真题风格例题
0/0 分子分母同时→0 洛必达 / 等价无穷小 / 泰勒展开 lim(x→0) (e^x − 1 − x) / x² ➜ 泰勒：=1/2
∞/∞ 分子分母同时→∞ 洛必达 / 抓大头（多项式比阶） lim(x→∞)(3x³+2x)/(5x³−x²) ➜ 抓大头：=3/5
0·∞ 一因子→0，另一→∞ 转化为 0/0：把趋于0的因子移到分母 lim(x→0⁺) x·ln x ➜ 写成 lnx/(1/x) ➜ 洛必达 =0
∞−∞ 两项均→∞，差不定 通分（分式差）/ 有理化（根式差） lim(x→0)(1/x − 1/sin x) ➜ 通分 ➜ 洛必达 =0
1^∞ 底→1，指数→∞ 取对数，用重要极限 lim(1+x)^(1/x)=e lim(x→0)(1+sin x)^(1/x) ➜ =e
∞^0 底→∞，指数→0 取对数化为 0·∞，再化为 0/0 lim(x→∞) x^(1/x) ➜ 取对数 ➜ =1
0^0 底→0，指数→0 取对数化为 0·∞ lim(x→0⁺) x^x ➜ 取对数 ➜ =1
💡 得分技巧 三步法口诀：①先看是不是不定式（直接代入判断）→ ②确定类型选策略 → ③执行计算。遇到 0·∞ 永远先转化为 0/0；遇到 1^∞ 永远取对数用重要极限。
⚠️ 常见错误 ① 不是不定式还强行用洛必达（如 lim(x→1) x²=1，直接代入即可）；② ∞−∞ 不分式就硬减（必须通分或有理化）；③ 1^∞ 直接认为等于1（大错！极限不一定为1）。
1.2 等价无穷小 约1.5h▼
🎯 目标分值： 4-6分 极限计算的加速器
📘 核心定义 当 x→0 时，若 lim f(x)/g(x)=1，则称 f(x) 与 g(x) 为等价无穷小，记作 f(x)∼g(x)。等价无穷小替换是求极限最常用的"简化"手段。
🔑 10个核心等价无穷小公式（x→0）
#原函数等价无穷小#原函数等价无穷小
1sin x∼ x6ln(1+x)∼ x
2tan x∼ x7e^x − 1∼ x
3arcsin x∼ x8a^x − 1∼ x·ln a
4arctan x∼ x9(1+x)^α − 1∼ αx
51−cos x∼ x²/210x−sin x∼ x³/6
💡 得分技巧 — 替换原则 乘除直接换（无条件）：在乘积或因式中，等价无穷小可以直接替换。
加减有条件（谨慎）：只有被替换的部分是更高阶的无穷小时才能换。一般原则：加减法中能不用就不用，先用泰勒展开验证再决定。
例题1：先等价简化再洛必达
1 lim(x→0)(tan x − sin x)/x³ — 识别：0/0型
2 注意：tan x − sin x 是加减，不能分别替换！正确做法：提出sin x → sin x(1/cos x − 1)=sin x·(1−cos x)/cos x
3 sin x ∼ x, 1−cos x ∼ x²/2 → 原式 = x·(x²/2)/x³ = 1/2
例题2：纯等价替换
1 lim(x→0)(e^x − 1)(sin 2x)/[x·ln(1+3x)]
2 全在乘除中，直接换：e^x−1∼x, sin2x∼2x, ln(1+3x)∼3x
3 = x·2x/(x·3x) = 2/3
⚠️ 常见错误 ① 加减法中直接套用等价替换（如 tan x−sin x 直接写成 x−x=0 ❌）；② 忽略替换条件"x→0"，当 x 趋近于其他值时公式不成立；③ 1−cos x 记成 x² 而忘记除以2。
1.3 洛必达法则 约1.5h▼
🎯 目标分值： 4-6分 0/0和∞/∞的标配解法
📘 核心定义 若 lim f(x)/g(x) 为 0/0 或 ∞/∞ 型，且 f'(x) 和 g'(x) 在去心邻域内可导，g'(x)≠0，则lim f(x)/g(x) = lim f'(x)/g'(x)（若右侧极限存在或为∞）。
⚠️ 使用前提（三个条件缺一不可） ① 必须是不定式 0/0 或 ∞/∞；② 分子分母在去心邻域内可导且分母导数≠0；③ 求导后的极限存在或为∞。
⚠️ 常见陷阱 陷阱1：非不定式直接代入就行，不要用洛必达。
陷阱2：求导后极限不存在（如震荡），不代表原极限不存在！典型反例：lim(x→∞)(x+sin x)/x = 1，但洛必达求导后 lim(1+cos x)/1 极限不存在——此时洛必达失效，应改用夹逼或其他方法。
💡 得分技巧 组合拳：等价无穷小（简化表达式）→ 洛必达（处理不定式）→ 等价无穷小（再次简化）。单独使用洛必达容易越导越复杂，必须搭配等价无穷小使用。
例题：等价+洛必达组合
1 lim(x→0)(e^x − e^(−x) − 2x)/(x − sin x)
2 等价：x−sin x ∼ x³/6；分子洛必达：e^x+e^(−x)−2 ➜ 再用泰勒或再洛两次
3 泰勒法更快：e^x=1+x+x²/2+x³/6+o(x³)，e^(−x)=1−x+x²/2−x³/6+o(x³)，代入分子=2·x³/6，分母=x³/6 ➜ = 2
1.4 泰勒展开 约2h▼
🎯 目标分值： 5-8分 极限计算的终极武器
📘 核心定义 泰勒公式将函数在某点展开为多项式+余项。对于极限计算，我们使用带皮亚诺余项的麦克劳林公式（在x=0处展开）。展开到与分母同阶即可消掉不定式。
🔑 6个标准展开式（x→0，带皮亚诺余项 o(xⁿ)）
函数泰勒展开式
eˣ1 + x + x²/2! + x³/3! + ... + xⁿ/n! + o(xⁿ)
sin xx − x³/3! + x⁵/5! − x⁷/7! + ... + o(x²ⁿ⁺¹)
cos x1 − x²/2! + x⁴/4! − x⁶/6! + ... + o(x²ⁿ)
ln(1+x)x − x²/2 + x³/3 − x⁴/4 + ... + (−1)ⁿ⁻¹xⁿ/n + o(xⁿ)
(1+x)ᵅ1 + αx + α(α−1)x²/2! + α(α−1)(α−2)x³/3! + ... + o(xⁿ)
1/(1−x)1 + x + x² + x³ + ... + xⁿ + o(xⁿ)   （几何级数）
💡 得分技巧 — 展开到几阶？ 黄金法则：若分母是 xᵏ（或最低阶为 xᵏ），则将分子展开到 xᵏ 阶（含 o(xᵏ)）。如果相减后 xᵏ 项消掉了，则继续展开到更高阶，直到不为零。
例题1：cos x的极限
1 lim(x→0)(1−cos x)/x² — 分母 x²，分子展开到 x²
2 cos x = 1 − x²/2! + o(x²)，代入：1−[1−x²/2+o(x²)] = x²/2+o(x²)
3 = (x²/2)/x² = 1/2
例题2：几个函数组合
1 lim(x→0)[sin x − x·cos x]/x³
2 sin x = x−x³/6+o(x³)，cos x = 1−x²/2+o(x²)，x·cos x = x−x³/2+o(x³)
3 分子 = (x−x³/6) − (x−x³/2) + o(x³) = x³/3+o(x³)，除以 x³ = 1/3
⚠️ 常见错误 ① 展开阶数不够导致有效项被高阶无穷小淹没（算出来0/0还没消掉）；② 忘记写 o(xⁿ) 余项（手写时可用"..."但考场上最好标明）；③ cos x 的展开式把 x²/2! 记成 x²/2 没关系（2!=2），但 sin x 的 x³/3! 必须记成 x³/6。

2.1 导数定义与几何意义 约1.5h▼
🎯 目标分值： 5-7分 定义直接出题 + 几何应用
📘 核心定义
f'(x₀) = lim(h→0) [f(x₀+h) − f(x₀)] / h
左导数：f'₋(x₀) = lim(h→0⁻) [f(x₀+h)−f(x₀)]/h
右导数：f'₊(x₀) = lim(h→0⁺) [f(x₀+h)−f(x₀)]/h
可导 ⇔ 左右导数存在且相等
💡 得分技巧 — 导数与连续的关系 可导 ⇒ 连续（逆否：不连续 ⇒ 不可导）
连续 ⇏ 可导（反例：y=|x| 在 x=0 连续但不可导）
这组关系在选择题中高频出现！
📘 几何意义 f'(x₀) 是曲线在点 (x₀, f(x₀)) 处的切线斜率。
切线方程：y − f(x₀) = f'(x₀)(x − x₀)
法线方程：y − f(x₀) = (−1/f'(x₀))(x − x₀)（f'(x₀)≠0）

2.4 隐函数与参数方程求导 约1.5h▼
🎯 目标分值： 5-8分 高频计算题
📘 隐函数求导 方程 F(x,y)=0 确定 y=y(x)，两边对 x 求导，y 视为 x 的函数，含 y 的项用链式法则。求导后解出 dy/dx。
例题：e^y + xy − e = 0，求 dy/dx
1 两边对 x 求导：e^y·y' + y + x·y' = 0
2 合并 y'：y'(e^y + x) = −y
3 dy/dx = −y/(e^y + x)
📘 参数方程求导
x = φ(t), y = ψ(t) → dy/dx = (dy/dt) / (dx/dt) = ψ'(t) / φ'(t)
二阶导公式：d²y/dx² = d(dy/dx)/dx = [d(dy/dx)/dt] / (dx/dt)
⚠️ 常见错误 参数方程的二阶导不是简单的分子二阶导除以分母二阶导！必须对一阶导再求一次导。

3.1 顺序表 约1h▼
🎯 目标分值： 2-4分 基础概念+代码
📘 核心定义 顺序表用一组地址连续的存储单元依次存储线性表的数据元素。支持随机存取，但插入删除需移动大量元素。
💡 得分技巧 — 复杂度速记 按位置存取：O(1)；按值查找：O(n)
插入/删除的平均移动次数：n/2（等概率下），时间复杂度 O(n)。 
/* 顺序表插入 — 第i个位置插入e */
int ListInsert(SqList *L, int i, ElemType e) {
    if (i < 1 || i > L->length + 1) return 0;  // 位置非法
    if (L->length >= MaxSize) return 0;             // 表满
    for (int j = L->length; j >= i; j--)
        L->data[j] = L->data[j - 1];         // 元素后移
    L->data[i - 1] = e;
    L->length++;
    return 1;
}

/* 顺序表删除 — 删除第i个位置元素，用e返回 */
int ListDelete(SqList *L, int i, ElemType *e) {
    if (i < 1 || i > L->length) return 0;
    *e = L->data[i - 1];
    for (int j = i; j < L->length; j++)
        L->data[j - 1] = L->data[j];       // 元素前移
    L->length--;
    return 1;
}
3.2 单链表 约2h▼

ListNode* reverseList(ListNode* head) {
    ListNode *prev = NULL, *curr = head, *next;
    while (curr != NULL) {
        next = curr->next;      // ① 保存下一个
        curr->next = prev;      // ② 反转指针
        prev = curr;            // ③ prev 前进
        curr = next;            // ④ curr 前进
    }
    return prev;  // prev 即新头节点
}

/* === 头插法反转（另一种写法）=== */
ListNode* reverseByHeadInsert(ListNode* head) {
    ListNode *newHead = NULL, *p = head, *tmp;
    while (p != NULL) {
        tmp = p->next;
        p->next = newHead;      // 头插到新链表
        newHead = p;
        p = tmp;
    }
    return newHead;
}
⚠️ 手写注意 三指针法反转链表的四个步骤顺序不能乱：先保存 next → 反转 curr → 移动 prev → 移动 curr。忘记保存 next 就丢失了后继节点！
3.3 双链表与循环链表 约0.5h▼
🎯 目标分值： 2-4分
💡 得分技巧 — 双链表插入的四步（口诀：先连后断） 在 p 之后插入 s：
① s→next = p→next；② p→next→prior = s；③ s→prior = p；④ p→next = s
关键：①② 先连"远"的，③④ 再断"近"的。顺序错了会导致断链。
链表类型判空条件特点
带头节点单链表head→next == NULL基础结构
循环单链表head→next == head尾节点→next 指向头
循环双链表head→next == head（或 head→prior == head）两个方向都闭环
3.4 栈 约1.5h▼
🎯 目标分值： 5-8分 栈应用必考大题
📘 核心定义 栈是后进先出（LIFO）的线性表。顺序栈用 top 指针指示栈顶位置。
入栈：top++ 再赋值（先移指针再放元素）
出栈：取值后 top--（先取元素再移指针）
💡 得分技巧 — 共享栈 两个栈共享同一数组空间，对向增长。栈1的栈底在数组0位置，栈2的栈底在数组maxSize-1位置。栈满条件：top1 + 1 == top2。 
/* === 括号匹配 — 必手写！=== */
int bracketMatch(char *str) {
    char stack[MaxSize]; int top = -1;
    for (int i = 0; str[i] != '\0'; i++) {
        if (str[i] == '(' || str[i] == '[' || str[i] == '{')
            stack[++top] = str[i];              // 左括号入栈
        else if (str[i] == ')' || str[i] == ']' || str[i] == '}') {
            if (top == -1) return 0;            // 栈空不匹配
            char c = stack[top--];
            if ((c=='(' && str[i]!=')') ||
                (c=='[' && str[i]!=']') ||
                (c=='{' && str[i]!='}')) return 0;
        }
    }
    return top == -1;  // 栈空则全部匹配
}

步骤详细说明
1. 运算符优先级*/ > +-；同级从左到右；遇到 ( 直接入栈
2. 操作数直接输出
3. 运算符栈空或栈顶为(则入栈；否则弹出所有优先级≥当前运算符的栈顶，再入栈
4. 右括号弹出栈顶直到遇到左括号（括号不输出）

3.5 队列 约1.5h▼
🎯 目标分值： 4-6分
📘 核心定义 队列是先进先出（FIFO）的线性表。顺序队列有假溢出问题 → 使用循环队列解决。
💡 循环队列核心公式（408高频考点）
front 指向队头元素
rear 指向队尾元素的下一个位置
判空rear == front
判满(rear + 1) % maxSize == front（牺牲一个单元）
元素个数(rear − front + maxSize) % maxSize
入队Q.data[rear] = x; rear = (rear + 1) % maxSize;
出队x = Q.data[front]; front = (front + 1) % maxSize;
/* === 循环队列入队出队 — 必手写！=== */
int EnQueue(SqQueue *Q, ElemType x) {
    if ((Q->rear + 1) % MaxSize == Q->front)
        return 0;                          // 队满
    Q->data[Q->rear] = x;
    Q->rear = (Q->rear + 1) % MaxSize;
    return 1;
}

int DeQueue(SqQueue *Q, ElemType *x) {
    if (Q->rear == Q->front)
        return 0;                          // 队空
    *x = Q->data[Q->front];
    Q->front = (Q->front + 1) % MaxSize;
    return 1;
}
⚠️ 常见错误 ① 混淆 front 和 rear 谁指队头谁指队尾下一个位置；② 判满忘记 +1 再取模；③ 元素个数公式忘了加 maxSize 导致负数。

4.1 串与模式匹配（KMP） 约1.5h▼
🎯 目标分值： 4-6分 next数组手算必考
📘 核心定义 KMP 算法通过next 数组实现模式匹配时主串指针 i 不回溯。简单匹配 O(mn)，KMP 优化为 O(m+n)。
💡 得分技巧 — next 数组手工计算步骤
j12345...
模式串 PP₁P₂P₃P₄P₅...
看前 j−1 个字符—P₁P₁P₂P₁P₂P₃P₁P₂P₃P₄...
最长公共前后缀长度—
next[j]01
口诀：next[1]=0, next[2]=1；之后取前 j−1 个字符的最长公共前后缀长度 +1。
例题：计算模式串 "abaabc" 的 next 数组
j123456
Pabaabc
前 j−1 个—"a""ab""aba""abaa""abaab"
最长前后缀—无无"a"(长1)"a"(长1)"ab"(长2)
next[j]011223
💡 nextval 优化 当 Pⱼ = Pnext[j] 时，nextval[j] = nextval[next[j]]（递归取），否则 nextval[j] = next[j]。优化后的 nextval 避免了重复比较已知不匹配的字符。
⚠️ 常见错误 ① next[1] 记成 1（正确是 0）——不同教材定义不同，408 用 next[1]=0；② 公共前后缀不能是整个字符串本身；③ 前 j−1 个字符而不是 j 个。
📘 KMP 匹配过程 主串指针 i 不回溯，模式串指针 j 失配时回退到 next[j]（即 j = next[j]），j=0 时 i++、j++。

#性质证明要点

4.3 二叉树遍历 约2h▼
🎯 目标分值： 5-10分 遍历+还原，大题必考
遍历方式递归口诀非递归策略
前序根→左→右栈：访问当前→右孩子入栈→走左
中序左→根→右栈：沿左链全入栈→出栈访问→转右子树
后序左→右→根双栈法（栈1根左右→栈2收集）或 pre指针标记
层序逐层从左到右队列辅助，出队时孩子入队
/* 中序非递归遍历 — 必手写！*/
void InOrder(BiTree T) {
    BiTree stack[MaxSize]; int top = -1;
    BiTree p = T;
    while (p || top != -1) {
        if (p) {
            stack[++top] = p;       // 沿左链入栈
            p = p->lchild;
        } else {
            p = stack[top--];       // 出栈访问
            visit(p);
            p = p->rchild;          // 转右子树
        }
    }
}
💡 得分技巧 — 遍历序列还原二叉树
给定序列能否唯一确定？方法
前序 + 中序✅ 能前序首节点=根 → 中序分左右 → 递归
中序 + 后序✅ 能后序尾节点=根 → 中序分左右 → 递归
前序 + 后序❌ 不能无法唯一区分左右子树（只有满二叉树才行）
层序 + 中序✅ 能层序第一个=根 → 中序分左右 → 递归
例题：前序=ABDEC，中序=DBEAC，还原二叉树
1 前序首 A=根，中序 DBE | A | C → 左子树=DBE，右子树=C
2 左子树前序=BDE，左子树中序=DBE → B=根，中序 D | B | E → 左=D，右=E
3 右子树只有 C
4 还原：A为根，左孩子B（左D右E），右孩子C

4.5 AVL树 约1.5h▼
🎯 目标分值： 4-6分 四种旋转画图必考
📘 核心定义 AVL 树是平衡二叉搜索树，任意节点的平衡因子（左子树高−右子树高）∈ {−1, 0, 1}。插入后从下往上检查，找到最小不平衡子树进行旋转调整。
💡 四种旋转（画图演示每一步）
类型判定操作记忆口诀
LLA的BF=2，A左孩子B的BF=1右单旋：B的右子树挂到A左边，B→right=A"左左则右转"
RRA的BF=−2，A右孩子B的BF=−1左单旋：B的左子树挂到A右边，B→left=A"右右则左转"
LRA的BF=2，A左孩子B的BF=−1先左旋后右旋：先对B左旋变成LL，再对A右旋"左右→左右转"
RLA的BF=−2，A右孩子B的BF=1先右旋后左旋：先对B右旋变成RR，再对A左旋"右左→右左转"
例题：依次插入 3, 2, 1, 4, 5, 6, 7 到空AVL树
1 插3：平衡。插2：平衡（3的左）。插1：3的BF=2，LL型 → 右单旋，2为根。
2 插4：2的右。插5：2右右两侧，2的BF=−2，RR型 → 左单旋（注意最小不平衡子树）。
3 插6：需要RL旋转。插7：需要RR旋转（左单旋）。
4 最终树结构：建议动手画一遍验证。
⚠️ 常见错误 ① LL 和 LR 搞混：关键看插入在左子树的哪一侧，不是看 BF 符号；② 旋转时忘记更新子树挂接关系；③ 最小不平衡子树选错（应该是离插入点最近的不平衡节点）。
4.6 哈夫曼树 约1h▼
🎯 目标分值： 3-5分
📘 核心定义 WPL（带权路径长度）= Σ wᵢ·lᵢ，其中 wᵢ 是叶子权值，lᵢ 是从根到该叶子的路径长度（边数）。哈夫曼树是 WPL 最小的二叉树。
💡 得分技巧 — 构造步骤 ① 将 n 个权值放入集合（每个是一个单节点树）；
② 每次选两个最小权值合并为一个新的内部节点（权值为两子权值之和）；
③ 重复直到只剩一棵树。
编码规则：左分支=0，右分支=1，哈夫曼编码是前缀编码（任一编码不是另一编码的前缀）。
例题：权值 {2, 3, 5, 7, 9}，构造哈夫曼树，求WPL和编码
1 选2和3 → 合并为5；集合 {5, 5, 7, 9}
2 选5和5 → 合并为10；集合 {7, 9, 10}
3 选7和9 → 合并为16；集合 {10, 16}；合并得 26
4 WPL = (2+3)×3 + 5×2 + 7×2 + 9×2 = 15+10+14+18 = 57
