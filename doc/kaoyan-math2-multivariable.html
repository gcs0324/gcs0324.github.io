§1 方法选择主线
偏导先固定其他变量→复合函数画依赖树→极值列驻点→二重积分先画区域→再决定直角或极坐标
极坐标面积元 dA=r dr dθ；这个 r 来自坐标变换的 Jacobian，不能遗漏
原则

先写适用条件和第一步，再计算。方法不满足条件时，即使最后数字碰巧正确也不算真正掌握。

§2 可直接套用的解题步骤

二重积分写积分限

识别信号题目给出平面区域或曲线边界，要求直角坐标累次积分、换序或极坐标计算。

  1. 1画出区域 D，标清边界方程、交点和对称性。
  2. 2先判断是否能用奇偶对称；圆、扇形、射线边界优先考虑极坐标。
  3. 3直角坐标中选竖切或横切，先写外变量在区域投影上的范围。
  4. 4固定外变量，沿扫描线写内变量的下界与上界；边界切换时必须分块。
  5. 5极坐标依次写 θ、r 的范围，并把面积元写成 r dr dθ。

结果检查把被积函数换成 1，所得积分应等于区域面积；用图形检查每条扫描线没有漏段或重复。

易错点只写投影范围而漏内层边界；区域需分块却硬写一重；极坐标漏掉 Jacobian 的 r。

§3 典型题怎么一步步做
教程例题 · 复合偏导画依赖树
z=f(u,v)，u=x+y，v=xy，求 ∂z/∂x。
1z 通过 u、v 两条路径依赖 x，因此两条链都要相加。
2uₓ=1，vₓ=y，所以 zₓ=fᵤuₓ+fᵥvₓ。
3得到 zₓ=fᵤ+yfᵥ，其中 fᵤ、fᵥ在 (x+y,xy) 处取值。
zₓ=fᵤ+yfᵥ；易错点是只写一条链。
教程例题 · 隐函数偏导
x²+y²+z²=1，z=z(x,y)，求 zₓ。
1对 x 求偏导时 y 固定，z 通过 x 变化。
22x+2z zₓ=0。
3当 z≠0 时 zₓ=-x/z；z=0 处该表示未必能把 z 看成光滑函数。
zₓ=-x/z，需满足 z≠0。
教程例题 · 二元无条件极值
求 f=x²+y²-2x-4y 的极小值。
1驻点方程 fₓ=2x-2=0，fᵧ=2y-4=0，得 (1,2)。
2Hessian 为 diag(2,2)，正定，所以是严格极小点。
3代入 f(1,2)=1+4-2-8=-5。
极小值 -5；配方 (x-1)²+(y-2)²-5 可反查。
教程例题 · 直角坐标二重积分
计算 D={x≥0,y≥0,x+y≤1} 上 ∬1 dA。
1画图得第一象限直角三角形；取 x 从 0 到 1。
2固定 x 时 y 从 0 到 1-x，所以积分为 ∫₀¹∫₀^(1-x)1 dy dx。
3结果 ∫₀¹(1-x)dx=1/2，与三角形面积一致。
1/2；几何面积是最直接的反向检查。
考试型练习 · 考试型练习
计算单位圆盘上 ∬(x²+y²)dA。
1区域和被积函数都含圆对称结构，取 x=r cosθ、y=r sinθ。
2积分为 ∫₀^(2π)∫₀¹ r²·r dr dθ=2π·1/4=π/2。
π/2；第三个 r 是面积元中的 Jacobian。
