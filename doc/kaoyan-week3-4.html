1.1 三大中值定理 约2h▼
🎯 目标分值： 8-12分 证明题核心战场
📘 罗尔定理（基础款） 若 f(x) 满足：① 在 [a,b] 上连续；② 在 (a,b) 内可导；③ f(a)=f(b)，则至少存在一点 ξ∈(a,b)，使 f'(ξ)=0。
几何意义：两端等高的连续光滑曲线，中间必有一处切线水平。
📘 拉格朗日中值定理（最常用） 若 f(x) 在 [a,b] 连续、(a,b) 可导，则至少存在一点 ξ∈(a,b)，使
f(b) − f(a) = f'(ξ)·(b − a)
几何意义：曲线上必有一处切线斜率等于两端点连线的斜率。罗尔定理是其 f(a)=f(b) 的特例。
📘 柯西中值定理（参数方程版） 若 f(x)、g(x) 在 [a,b] 连续、(a,b) 可导，且 g'(x)≠0，则至少存在一点 ξ，使
[f(b) − f(a)] / [g(b) − g(a)] = f'(ξ) / g'(ξ)
理解：把拉格朗日里的曲线换成参数方程 (g(t), f(t)) 就是柯西。三个定理是逐级推广：罗尔 ⊂ 拉格朗日 ⊂ 柯西。
定理关键条件结论典型用法
罗尔f(a)=f(b)f'(ξ)=0证方程有根 / f'(x) 零点存在
拉格朗日仅连续+可导f(b)−f(a)=f'(ξ)(b−a)证不等式、估计差值
柯西两个函数+g'≠0两函数增量比=导数比双中值问题（含两个 ξ）
💡 得分技巧 - 选哪个定理？ ① 结论里只有一个 ξ 且出现 f'(ξ)：优先罗尔或拉格朗日；
② 结论是 f(b)−f(a) 与 (b−a) 的关系：拉格朗日；
③ 结论含两个函数的增量比或两个不同的 ξ：柯西，或两次拉格朗日。
⚠️ 常见错误 ① 验证定理时不检查"连续+可导"就直接套（如分段函数分界点不可导，定理失效）；② 柯西定理忘记验证 g'(x)≠0，否则分母 g(b)−g(a) 可能为 0 无意义；③ 把 ξ 写成闭区间 [a,b] 内（必须是开区间 (a,b)）。
1.2 辅助函数构造（大题难点） 约1.5h▼
🎯 目标分值： 6-10分 证明题"卡人"的题
📘 核心思路 要证"存在 ξ 使 F(ξ, f(ξ), f'(ξ))=0"，而定理直接套不上时，构造一个辅助函数 F(x)，使其满足罗尔定理条件，且 F'(x)=0 恰好等价于要证的等式。本质是逆向凑微分。
🔑 必背 6 个辅助函数套路（看到左式→构造右式）
结论中出现的形式构造辅助函数 F(x)记忆逻辑
ξ·f'(ξ) + f(ξ)F(x) = x·f(x)(xf)' = f + xf'
ξ·f'(ξ) + n·f(ξ)F(x) = xⁿ·f(x)(xⁿf)' = nxⁿ⁻¹f + xⁿf'
f'(ξ) + f(ξ)F(x) = eˣ·f(x)(eˣf)' = eˣ(f+f')
f'(ξ) − f(ξ)F(x) = e⁻ˣ·f(x)(e⁻ˣf)' = e⁻ˣ(f'−f)
f'(ξ) + k·f(ξ)F(x) = eᵏˣ·f(x)(eᵏˣf)' = eᵏˣ(f'+kf)
f'(ξ)·g(ξ) − f(ξ)·g'(ξ)F(x) = f(x)/g(x)(f/g)' = (f'g−fg')/g²
例题：f 在 [0,1] 连续可导，f(0)=f(1)=0，证存在 ξ 使 f'(ξ)+f(ξ)=0
1 识别形式：f'(ξ)+f(ξ) → 查表构造 F(x)=eˣ·f(x)
2 验证罗尔条件：F 连续可导，F(0)=e⁰·f(0)=0，F(1)=e¹·f(1)=0，故 F(0)=F(1)
3 由罗尔定理：存在 ξ∈(0,1) 使 F'(ξ)=0，即 eξ(f'(ξ)+f(ξ))=0
4 eξ≠0，故 f'(ξ)+f(ξ)=0，得证。
💡 得分技巧 - 构造三步法 ① 识别：把结论里的 ξ 换成 x，整理成 F(x, f, f')=0；
② 凑微分：观察哪个函数求导后能产生这个式子（查上表）；
③ 验证：检查 F 在端点的值是否相等（凑罗尔）或直接用拉格朗日。
记不住表就记原理：f' 前面有什么因子，就把 e 的那个因子次方乘上去。
⚠️ 双中值问题 结论含两个不同的 ξ₁、ξ₂（如 f'(ξ₁)+f'(ξ₂)=k）：把区间 [a,b] 分成两段 [a,c] 和 [c,b]，各用一次拉格朗日/罗尔。c 的选取是关键，常取中点或由题目条件确定。
1.3 单调性与极值 约1.5h▼
🎯 目标分值： 6-10分 选择填空+大题常客
📘 单调性判定 设 f 可导：① f'(x)>0 ⇒ f 单调增；② f'(x)<0 ⇒ f 单调减。
注意：单调增的区间允许个别点 f'(x)=0（如 y=x³ 在 x=0），只要 f'(x) 不变号即可。
📘 极值 - 两个充分条件 必要条件：若 f 在 x₀ 可导且取极值，则 f'(x₀)=0（称为驻点）。但驻点未必是极值点（如 x³ 在 0）。
第一充分条件（看变号）：x₀ 处 f' 左正右负 ⇒ 极大；左负右正 ⇒ 极小；不变号 ⇒ 不是极值。
第二充分条件（看二阶导）：f'(x₀)=0 且 f''(x₀)<0 ⇒ 极大；f''(x₀)>0 ⇒ 极小；f''(x₀)=0 ⇒ 失效，改用第一充分条件。
💡 得分技巧 - 极值求法标准流程 ① 求一阶导 f'(x)；② 解 f'(x)=0 得驻点，并找出不可导点；③ 用第一或第二充分条件逐一判定；④ 不可导点（如 |x| 在 0）也可能是极值点，必须列入考察！
例题：求 f(x)=x³−3x+1 的极值
1 f'(x)=3x²−3=3(x+1)(x−1)，令 =0 得驻点 x=−1, x=1
2 f''(x)=6x。f''(−1)=−6<0 ⇒ x=−1 是极大值点，极大值 f(−1)=3
3 f''(1)=6>0 ⇒ x=1 是极小值点，极小值 f(1)=−1
⚠️ 常见错误 ① 把极值和最值混为一谈（极值是局部概念，最值是整体概念）；② 只找驻点忘记不可导点；③ f''(x₀)=0 时直接判"不是极值"（失效≠不是，要用第一充分条件复查）。
1.4 最值与应用问题 约1h▼
🎯 目标分值： 5-8分 应用大题
📘 闭区间最值 f 在 [a,b] 上的最值只可能在三类点取得：① 驻点（f'=0）；② 不可导点；③ 端点 a、b。
求法：把这三类点的函数值全部算出来，比大小，最大者为最大值，最小者为最小值。
💡 得分技巧 - 应用题建模四步 ① 设变量：设自变量 x 和目标量 y；② 建函数：把 y 写成 x 的函数（可能借助约束条件消元）；③ 求驻点：求 y' 并令 =0（实际题唯一驻点通常就是最值点）；④ 验证：用第二充分条件或实际问题意义确认最大/最小，并回答。
例题：做一无盖圆柱形铁罐，容积 V 固定，求用料最省的尺寸
1 设底半径 r、高 h。约束：V=πr²h ⇒ h=V/(πr²)
2 表面积 S=πr²（底）+2πrh（侧）=πr²+2V/r
3 S'=2πr−2V/r²，令 =0 ⇒ r³=V/π ⇒ r=∛(V/π)
4 S''=2π+4V/r³>0，故为极小值点，此时 h=r，即高=底半径时用料最省。
1.5 凹凸性与拐点 约1h▼
🎯 目标分值： 4-6分
📘 凹凸性判定（数二用二阶导） 设 f 二阶可导：① f''(x)>0 ⇒ 曲线凹（开口向上，∪）；② f''(x)<0 ⇒ 曲线凸（开口向下，∩）。
注意：不同教材"凹/凸"定义可能相反，408/数二以"f''>0 为凹"为准。
📘 拐点 曲线凹凸性改变的点（连续曲线上的点）。
必要条件：若 (x₀, f(x₀)) 是拐点且 f''(x₀) 存在，则 f''(x₀)=0。
充分条件：f''(x₀)=0 且 f'' 在 x₀ 两侧变号 ⇒ 拐点。
💡 极值点 vs 拐点对照
极值点拐点
看几阶导一阶导 f'二阶导 f''
必要条件f'(x₀)=0f''(x₀)=0
充分条件f' 变号f'' 变号
几何切线水平/尖点凹凸翻转
⚠️ 常见错误 ① 把拐点写成 x=x₀（拐点是点，必须写 (x₀, f(x₀)) 坐标对）；② f''(x₀)=0 就断定是拐点（必须验证变号，如 x⁴ 在 0 处 f''=0 但不是拐点）。
1.6 渐近线 约1h▼
🎯 目标分值： 4-6分 三类渐近线全求
类型求法关键点
水平渐近线 lim(x→∞) f(x)=A ⇒ y=A x→+∞ 和 x→−∞ 都要算，可能两条不同
铅直渐近线 lim(x→x₀) f(x)=∞ ⇒ x=x₀ 在无定义点/分母零点/区间端点处找，左右极限都要看
斜渐近线 k=lim(x→∞) f(x)/x，b=lim(x→∞)[f(x)−kx] ⇒ y=kx+b k 存在且≠0、b 存在才有；有水平则无同侧斜
例题：求 f(x)=x·ln(e+1/x) 的渐近线
1 铅直：x=0 是分母零点。lim(x→0⁺) x·ln(e+1/x)，令 t=1/x→+∞，=lim ln(e+t)/t = 0，不是∞，无铅直渐近线
2 水平：lim(x→∞) x·ln(e+1/x)=lim x·(1/x)=1（等价 ln(1+t)~t），故 y=1 是水平渐近线
3 斜：已有水平渐近线，x→∞ 同侧不再有斜渐近线。
⚠️ 常见错误 ① 只算 x→+∞ 忘记 x→−∞（左右水平渐近线可能不同）；② 铅直渐近线只在分母零点找，忽略 ln、arctan 等的边界；③ 有水平渐近线还硬求斜渐近线（同侧二者互斥）。
1.7 曲率与方程求根 约0.5h▼
🎯 目标分值： 2-4分
🔑 曲率公式（数二考纲要求）
K = |y''| / (1 + y'²)^(3/2)
曲率半径：R = 1/K
理解：曲线弯得越厉害 K 越大；直线 y''=0 故 K=0。
📘 方程求根 - 两个工具 零点定理：f 在 [a,b] 连续，f(a)·f(b)<0 ⇒ 至少存在一个根 ξ∈(a,b)。
单调性+零点定理：证明唯一根：先用零点定理证存在，再用 f' 不变号（单调）证唯一。
💡 根的个数判定流程 ① 求 f'，确定单调区间；② 每个单调区间端点（含 ±∞）函数值变号 ⇒ 该区间恰一根；③ 不变号 ⇒ 无根。把各区间的根数相加。

2.1 概念与22个基本公式 约1.5h▼
🎯 目标分值： 5-8分 积分是微分方程/定积分的基础
📘 核心定义 若 F'(x)=f(x)，则称 F(x) 为 f(x) 的一个原函数。不定积分 ∫f(x)dx = F(x)+C，其中 C 是任意常数。
本质：求导的逆运算。切记 +C！考试漏写 C 扣分。
💡 两条线性性质 ① ∫[a·f(x) ± b·g(x)]dx = a·∫f(x)dx ± b·∫g(x)dx（系数可提、加减可拆）；
② (∫f(x)dx)' = f(x)；d(∫f(x)dx) = f(x)dx —— 积分与求导互逆。
🔑 22个基本积分公式（必须秒记，对照导数表反推）

2.2 第一类换元法（凑微分） 约2h▼
🎯 目标分值： 8-12分 最高频积分法
📘 核心思想 ∫f(φ(x))·φ'(x)dx，令 u=φ(x)，则 du=φ'(x)dx，原式 = ∫f(u)du = F(u)+C = F(φ(x))+C。
口诀："凑微分"——把 φ'(x)dx 凑成 d(φ(x))，整体换元。
🔑 8个常见凑微分模式（看到->这样凑）
被积式中出现凑成典型例子
f(ax+b)a·dx = d(ax+b)∫e^(2x+1)dx = ½e^(2x+1)+C
x·f(x²)dxx dx = ½d(x²)∫x·cos(x²)dx = ½sin(x²)+C
(1/x)·f(ln x)dx(1/x)dx = d(ln x)∫(ln x)²/x dx = (ln x)³/3+C
(1/√x)·f(√x)dx(1/√x)dx = 2d(√x)∫e^√x/√x dx = 2e^√x+C
eˣ·f(eˣ)dxeˣdx = d(eˣ)∫eˣ/(1+eˣ)dx = ln(1+eˣ)+C
cos x·f(sin x)dxcos x dx = d(sin x)∫cos³x·sin x dx = −cos⁴x/4+C
1/(1+x²)·f(arctan x)dx=d(arctan x)∫e^(arctan x)/(1+x²)dx
1/√(1−x²)·f(arcsin x)dx=d(arcsin x)类似上
例题1：∫(2x+1)/(x²+x+1) dx
1 识别：分子 2x+1 恰是分母 x²+x+1 的导数，凑微分
2 原式 = ∫d(x²+x+1)/(x²+x+1) = ln|x²+x+1|+C
例题2：∫sin³x dx
1 拆出 sin x dx 凑成 −d(cos x)：原式=∫sin²x·sin x dx = −∫(1−cos²x)d(cos x)
2 令 u=cos x：= −∫(1−u²)du = −u + u³/3 + C
3 回代 = −cos x + cos³x/3 + C
💡 得分技巧 - 凑微分三问 看到积分先问自己三句：① 分子是不是分母的导数？② 有没有 x·dx 能凑 x²？③ 有没有三角函数能凑 sin/cos？命中任何一个，直接换元。
2.3 第二类换元法（三角换元） 约1.5h▼
🎯 目标分值： 5-8分 含根号的积分
📘 核心思想 被积函数含根号且凑微分无效时，令 x=φ(t) 消去根号，化简后再积分。与第一类相反：这里是主动设新变量替换 x。
根号形式换元消根依据定义域
√(a²−x²)x = a·sin t1−sin²t = cos²tt∈(−π/2, π/2)
√(a²+x²)x = a·tan t1+tan²t = sec²tt∈(−π/2, π/2)
√(x²−a²)x = a·sec tsec²t−1 = tan²tt∈(0, π/2)
例题：∫√(1−x²) dx
1 令 x=sin t，dx=cos t dt，√(1−x²)=cos t
2 原式=∫cos t·cos t dt = ∫cos²t dt = ∫(1+cos2t)/2 dt = t/2 + sin2t/4 + C
3 回代：t=arcsin x，sin2t=2sin t·cos t=2x√(1−x²)
4 = ½·arcsin x + ½·x·√(1−x²) + C
💡 得分技巧 - 回代技巧 三角换元回代时画一个直角三角形，标出对边=x、斜边=a（或邻边），直接读出其它三角函数值，避免记不住辅助角公式。这是必练动作。
⚠️ 倒代换（补充） 分母次数比分子高很多时（如 ∫dx/(x⁴·√(1+x²))），令 x=1/t 可降次化简。这是第二类换元的补充手段，不常用但要认识。
2.4 分部积分法（反对幂三指） 约2h▼
🎯 目标分值： 8-12分 两大积分法之一
📘 核心公式
∫u dv = u·v − ∫v du
思想：把被积函数拆成 u 和 dv 两部分，对 dv 积分得 v，把"求 ∫u dv"转化为"求 ∫v du"。适用于两类不同函数乘积的积分。
💡 得分技巧 - "反对幂三指"选 u 口诀 按反三角函数 > 对数函数 > 幂函数 > 三角函数 > 指数函数的优先级选 u（排在前面的当 u，排在后面的连同 dx 当 dv）。
原理：排前面的求导变简单（ln→1/x，arctan→有理式），排后面的积分不变难（sin→−cos，eˣ→eˣ）。选错 u 会越积越复杂！
被积函数类型选 u选 dv示例
幂 × 指数（xⁿ·eˣ）xⁿeˣ dx∫x·eˣ dx
幂 × 三角（xⁿ·sin x）xⁿsin x dx∫x²·cos x dx
幂 × 对数（xⁿ·ln x）ln xxⁿ dx∫x·ln x dx
幂 × 反三角（xⁿ·arctan x）arctan xxⁿ dx∫arctan x dx
指数 × 三角（eˣ·sin x）任选另一∫eˣ·sin x dx（循环两次）
例题1：∫x·eˣ dx
1 幂<指数，选 u=x，dv=eˣdx ⇒ v=eˣ
2 = x·eˣ − ∫eˣ·1 dx = x·eˣ − eˣ + C = eˣ(x−1)+C
例题2：∫eˣ·sin x dx（循环型）
1 选 u=sin x，dv=eˣdx：原式 = eˣ·sin x − ∫eˣ·cos x dx
2 对 ∫eˣ·cos x dx 再分部：u=cos x，= eˣ·cos x + ∫eˣ·sin x dx
3 回代：原式 = eˣ·sin x − eˣ·cos x − ∫eˣ·sin x dx
4 右边又出现原式，移项：2·原式 = eˣ(sin x − cos x)，故原式 = ½·eˣ(sin x − cos x)+C
⚠️ 常见错误 ① u、dv 选反方向（如 ∫x·eˣ dx 选 u=eˣ），导致幂次升高越积越繁；② 忘记回代或循环型忘记移项除以 2；③ 连续分部时符号出错（每次分部前面是减号）。

3.1 图的基本概念 约0.5h▼
🎯 目标分值： 3-5分 概念选择填空
概念定义/性质
完全图无向：任意两点连边，边数 = n(n−1)/2；有向：任意两点双向连，弧数 = n(n−1)
度无向图：所有顶点度数之和 = 2e；有向图：入度和 = 出度和 = e
连通/强连通无向图两顶点有路径则连通；有向图两顶点相互可达则强连通

有向图：∑出度 = ∑入度 = e。

3.3 图的遍历 BFS / DFS 约1.5h▼
🎯 目标分值： 5-8分 代码+手算模拟
BFS（广度优先）DFS（深度优先）
数据结构队列栈（或递归）
访问顺序层序扩散，先近后远一条路走到底再回退
邻接矩阵复杂度O(V²)O(V²)
邻接表复杂度O(V+E)O(V+E)
生成树广度优先生成树深度优先生成树
应用无权图最短路径、连通性连通性、拓扑排序、判环
/* BFS - 必手写！队列实现 */
int visited[MaxVex];
void BFS(ALGraph G, int v) {
    int queue[MaxVex], front = 0, rear = 0;
    visit(v); visited[v] = 1;
    queue[rear++] = v;                       // 起点入队
    while (front != rear) {
        int u = queue[front++];            // 出队
        for (ArcNode *p = G.vertices[u].firstarc; p; p = p->nextarc) {
            int w = p->adjvex;
            if (!visited[w]) {
                visit(w); visited[w] = 1;
                queue[rear++] = w;         // 未访问邻接点入队
            }
        }
    }
}

/* DFS - 必手写！递归实现 */
void DFS(ALGraph G, int v) {
    visit(v); visited[v] = 1;
    for (ArcNode *p = G.vertices[v].firstarc; p; p = p->nextarc) {
        int w = p->adjvex;
        if (!visited[w])
            DFS(G, w);                  // 递归深入
    }
}
⚠️ 手写注意 BFS 中"访问+标记+入队"必须同时进行，不能先入队后访问，否则同一顶点会重复入队。DFS 递归版注意 visited 标记在 visit 之后立即置位。
💡 性能对比记忆 邻接矩阵遍历要扫整行（V 个），共 V 个顶点 ⇒ O(V²)；邻接表每条边访问一次、每个顶点访问一次 ⇒ O(V+E)。稀疏图必用邻接表。
3.4 最小生成树 Prim / Kruskal 约1.5h▼
🎯 目标分值： 5-8分 手算必考
📘 最小生成树（MST） 连通无向图中，边权之和最小的生成树。含 n 个顶点、n−1 条边。
Prim（普里姆）Kruskal（克鲁斯卡尔）
策略从某点出发，每次选连接已选集合与未选集合的最小权边所有边按权排序，依次选不成环的最小边
数据结构lowCost 数组并查集判环
时间复杂度O(V²)O(E·logE)
适用稠密图稀疏图
结果两种算法MST权值相同（但边集合可能不同）同左
例题：Prim 手算步骤（从 V0 开始）
1 U={V0}，候选边：V0 连出的所有边，选最小权边 (V0,Vi) 加入
2 U={V0,Vi}，更新候选边：新顶点 Vi 连向 U 外顶点的边，与原候选取较小者
3 重复选最小、加入、更新，直到 U 含全部顶点（共选 n−1 条边）
💡 得分技巧 - Kruskal 判环 Kruskal 每次加边前判断：边的两端点是否已在同一集合（用并查集 find）。若已连通则加此边成环，跳过；否则合并两集合并加入。
⚠️ 常见错误 ① Prim 每次只选一条边，不是把所有候选边都加；② Kruskal 忘记判环导致成环；③ 认为两算法 MST 边集合必然相同（权值和相同，但边可能不同，当有等权边时）。
3.5 最短路径 Dijkstra / Floyd 约1.5h▼
🎯 目标分值： 6-10分 Dijkstra手算表格
Dijkstra（迪杰斯特拉）Floyd（弗洛伊德）
求解单源最短路径所有顶点对最短路径
策略贪心：每次选距离源点最近的未确定顶点动态规划：以每个顶点做中转尝试松弛
限制不能有负权边可有负权，但不能有负权回路
复杂度O(V²)O(V³)
📘 Dijkstra 手算流程（每步记表格！） ① 初始化：dist[源]=0，其余=∞，所有点未确定；
② 选 dist 最小的未确定顶点 u，标记为已确定；
③ 用 u 的出边松弛邻居：dist[w] = min(dist[w], dist[u]+边权)；
④ 重复②③，直到所有顶点确定（共 V 轮）。
例题：Dijkstra 表格法（5顶点图）
轮次选定顶点dist[V1]dist[V2]dist[V3]dist[V4]
初始V010∞30100
1V1(10)10✓10+50=6030100
2V3(30)-6030✓min(100,30+60)=90
3V2(60)-60✓-min(90,60+10)=70
4V4(70)---70✓
结果：V0→V1:10, V0→V3:30, V0→V2:60, V0→V4:70
💡 Floyd 核心三重循环 for k: for i: for j: dist[i][j] = min(dist[i][j], dist[i][k]+dist[k][j])
k 必须在最外层--表示"允许经过顶点 0..k 做中转"时的最短路径。
⚠️ 常见错误 ① Dijkstra 用于含负权的图（贪心策略失效，得错误结果）；② Dijkstra 已确定顶点重复松弛（已确定的不再更新）；③ Floyd 循环顺序写错（k 放内层会出错）。
3.6 拓扑排序（AOV网） 约1h▼
🎯 目标分值： 4-6分
📘 AOV网与拓扑排序 AOV网：用顶点表示活动、边表示活动先后关系的有向无环图（DAG）。
拓扑排序：把 AOV 网的顶点排成线性序列，使所有有向边 u→v 中 u 排在 v 前。
💡 得分技巧 - 拓扑排序算法步骤 ① 选一个入度为0的顶点输出；
② 删除该顶点及其所有出边（即后继顶点入度−1）；
③ 重复①②直到全部输出（成功）或无入度为0顶点但有剩余（存在环，失败）。
应用：拓扑排序能检测有向图是否有环--若输出顶点数 < 总顶点数，则有环。 
/* 拓扑排序 - 必手写！入度数组+队列/栈 */
int inDegree[MaxVex];
int *TopologicalSort(ALGraph G) {
    int stack[MaxVex], top = -1, count = 0;
    static int result[MaxVex];
    for (int i = 0; i < G.vexNum; i++)
        if (inDegree[i] == 0) stack[++top] = i;   // 入度为0入栈
    while (top != -1) {
        int u = stack[top--];
        result[count++] = u;                       // 输出
        for (ArcNode *p = G.vertices[u].firstarc; p; p = p->nextarc) {
            int w = p->adjvex;
            if (--inDegree[w] == 0) stack[++top] = w;  // 入度减到0入栈
        }
    }
    if (count < G.vexNum) return NULL;       // 有环
    return result;
}
⚠️ 拓扑排序不唯一 当多个顶点入度同时为0时，输出顺序不唯一。选择题常考"以下哪个不是合法拓扑序列"。
3.7 关键路径（AOE网） 约0.5h▼
🎯 目标分值： 3-5分
📘 AOE网 用顶点表示事件、边表示活动（带权=活动耗时）的有向无环图。通常一个源点（入度0）、一个汇点（出度0）。
关键路径：从源点到汇点路径长度最长的路径，决定工程最短工期。
量含义求法
ve(j) 事件最早发生到该事件最晚也得等的时间拓扑正向：ve(j)=max(ve(i)+d(i,j))
vl(i) 事件最迟发生不延误工期的最晚发生逆拓扑：vl(i)=min(vl(j)−d(i,j))
e(k) 活动最早开始活动弧尾事件的 vee(k)=ve(弧尾)
l(k) 活动最迟开始不延误工期的最晚开始l(k)=vl(弧头)−d(k)
关键活动l(k)=e(k) 的活动时间余量 l−e=0
💡 得分技巧 - 关键路径四步 ① 拓扑排序求各事件 ve（正向取 max）；② 逆拓扑求 vl（逆向取 min）；③ 求各活动 e、l；④ l=e 的活动是关键活动，连起来即关键路径。
⚠️ 常见错误 ① 混淆 AOV（顶点=活动）和 AOE（边=活动）；② 关键路径唯一性（可能有多条，缩短工期要缩短所有关键路径上的活动才有意义）；③ 缩短一个关键活动就以为能缩短总工期（需缩短所有关键路径共有的活动）。

4.1 顺序查找与折半查找 约1h▼
🎯 目标分值： 4-6分 折半判定树必考
方法前提ASL（成功）复杂度
顺序查找无(n+1)/2O(n)
折半查找顺序存储 + 有序≈ log₂(n+1)−1O(log n)
分块查找块间有序、块内无序介于顺序与折半O(√n) 量级
📘 折半查找判定树 折半查找的过程对应一棵判定树：中间元素为根，左半为左子树、右半为右子树。
关键性质：判定树是平衡二叉树（但未必是满二叉树）；查找长度 = 该元素在树上的层数；ASL = 各层元素数 × 层数之和 / n。
例题：序列 {7,10,13,16,19,22,25} 折半查找判定树
1 mid=16 为根，左子树{7,10,13}，右子树{19,22,25}
2 左子树 mid=10，再分{7}和{13}；右子树 mid=22，再分{19}和{25}
3 树形：第1层16，第2层10、22，第3层7、13、19、25
4 ASL = (1×1 + 2×2 + 3×4)/7 = 17/7 ≈ 2.43
⚠️ 常见错误 ① 折半查找用于链表（必须顺序存储，链表不支持随机访问）；② 折半判定树误认为一定是完全二叉树（是平衡的，但未必填满最后一层）；③ mid 计算用 (low+high)/2 与 low+(high−low)/2 在大数时可能有溢出差异（考试一般不考，了解即可）。
4.2 散列表（Hash 表） 约1.5h▼
🎯 目标分值： 5-8分 ASL手算必考
冲突处理方法查找ASL特点
线性探测法冲突后顺序往后找下一个空位 d=(H(k)+i)%m会产生"聚集"，ASL较高
平方探测法d=(H(k)+i²)%m，i=0,1,2,...缓解聚集，但未必探查到所有位置
链地址法同义词挂在同一链表无聚集，ASL最低，适合频繁增删
📘 装填因子 α α = 表中记录数 / 表长。α 越大冲突越频繁、ASL 越大。散列表查找效率主要取决于 α，而非表长或记录数本身。
例题：H(k)=k%11，线性探测，插入 {12,23,34,45,10,21}
1 H(12)=1 -> 位置1：12
2 H(23)=1 冲突 -> 探测位置2：23
3 H(34)=1 冲突 -> 探测2冲突 -> 位置3：34
4 H(45)=1 冲突 -> 探测2,3冲突 -> 位置4：45
5 H(10)=10 -> 位置10：10
6 H(21)=10 冲突 -> 探测位置0：21
7 ASL成功=(1+2+3+4+1+2)/6=13/6≈2.17；ASL失败：每个散列地址探查到空为止的次数求和/11
💡 得分技巧 - ASL 两种计算 成功 ASL：每个已存元素的比较次数之和 / 元素数（注意冲突元素的比较次数含探查步数）。
失败 ASL：对每个散列地址 H，从该地址探查到第一个空位置的次数，求和 / 表长。失败 ASL 分母是表长 m，不是元素数！
⚠️ 常见错误 ① 失败 ASL 用元素数做分母（应表长 m）；② 线性探测遇到表尾忘记回绕到表头取模；③ 链地址法的 ASL 漏算空链表（空链表比较1次即判定失败）。
4.3 插入排序（直接/折半/希尔） 约1h▼
🎯 目标分值： 3-5分
算法最好最坏平均空间稳定

💡 得分技巧 - 直接插入 vs 折半插入 直接插入：边比较边后移，顺序找插入位置。折半插入：先用折半查找定插入位置（减少比较次数到 O(log n)），再一次性后移。两者移动次数相同（都要后移腾位），故时间复杂度仍 O(n²)，但折半版比较次数更少。
⚠️ 常见错误 ① 认为折半插入时间复杂度是 O(n log n)（移动仍是 O(n²)，总仍 O(n²)）；② 希尔排序认为稳定（由于跨步长交换，相同元素相对顺序可能改变，不稳定）。
4.4 交换排序（冒泡 + 快排） 约1.5h▼
🎯 目标分值： 6-10分 快排划分手算必考
算法最好最坏平均空间稳定
冒泡排序O(n)O(n²)O(n²)O(1)✓ 稳定
快速排序O(n log n)O(n²)O(n log n)O(log n) 栈✗ 不稳定
💡 快排最坏情况 待排序列有序或逆序时，每次划分极度不平衡（一边空），退化为 O(n²)。平均 O(n log n) 是内排序中平均最快的之一。空间是递归栈深度：最好 O(log n)，最坏 O(n)。 
/* 快排划分 - 必手写！Hoare或挖坑法 */
int Partition(int A[], int low, int high) {
    int pivot = A[low];                  // 取第一个为枢轴
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];                // 比枢轴小的移到左边
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];                // 比枢轴大的移到右边
    }
    A[low] = pivot;                      // 枢轴归位
    return low;                        // 返回枢轴位置
}
void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int pos = Partition(A, low, high);
        QuickSort(A, low, pos - 1);
        QuickSort(A, pos + 1, high);
    }
}
⚠️ 快排划分手算 每轮选定枢轴，从两端交替扫描：先从右往左找比枢轴小的，再从左往右找比枢轴大的，交换/填坑，直到指针相遇，枢轴归位。左右指针交替移动的方向和时机是手算易错点。

🎯 目标分值： 4-6分
算法最好/最坏/平均空间稳定特点

基数排序O(d(n+r))O(r)✓ 稳定不需比较，按位分配收集
💡 堆排序考点 建堆：从最后一个非叶子节点（⌊n/2⌋）开始，从下往上逐个下沉调整，O(n)。
排序：堆顶与末尾交换，堆大小−1，再下沉调整，重复 n−1 次。
大根堆：根>左右孩子，用于升序；小根堆用于降序。
💡 归并排序 二路归并：把相邻有序子序列两两合并。递归拆分到单元素，再两两合并。时间恒为 O(n log n)（无最坏退化），但需要 O(n) 辅助空间。是稳定的。
⚠️ 常见错误 ① 简单选择排序认为稳定（跨距离交换会破坏稳定性，不稳定）；② 堆排序建堆从根往下调（应从最后非叶子节点⌊n/2⌋往上）；③ 基数排序用于浮点数（只适用于关键字可按位分解的，如整数、字符串）。
