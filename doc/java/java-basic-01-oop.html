1. OOP 三大特性

封装（Encapsulation）

将数据和操作数据的方法封装在类中，通过访问修饰符控制可见性，隐藏实现细节。

修饰符同类同包子类其他
private✅❌❌❌
（默认）✅✅❌❌
protected✅✅✅❌
public✅✅✅✅

继承（Inheritance）

Java 只支持单继承（extends），通过继承复用父类代码，子类可以重写父类方法。

  • 构造器不被继承，但子类构造器第一行隐式调用 super()
  • final 类不可继承，final 方法不可重写
  • 继承体现 is-a 关系，组合体现 has-a 关系（优先组合而非继承）

多态（Polymorphism）

同一接口/父类引用，指向不同子类对象，运行时动态绑定（动态分派）。

Animal a = new Dog();   // 编译期看左边，运行期看右边
a.speak();              // 调用 Dog.speak()，动态绑定
💡 多态必须满足：继承/实现 + 方法重写 + 父类引用指向子类对象。成员变量不参与多态（编译期绑定）。

2. 接口 vs 抽象类

对比维度接口（interface）抽象类（abstract class）
实例化❌ 不可❌ 不可
继承/实现类可实现多个接口单继承
成员变量public static final 常量任意访问修饰符
方法abstract + default + static（JDK8）任意，可含具体方法
构造器❌ 无✅ 有
适用场景定义行为契约（能做什么）代码复用（是什么）
Spring中大量接口抽象（BeanFactory 等）模板方法模式（AbstractBeanFactory）
💡 JDK 8 接口可有 default 方法（解决接口演进问题）和 static 方法；JDK 9 接口可有 private 方法。
interface Flyable {
    void fly();                        // 抽象方法（隐式 public abstract）
    default void land() { ... }        // JDK8 默认方法
    static Flyable of(String type) {   // JDK8 静态方法
        return ...;
    }
}

3. 重写 vs 重载

对比重写（Override）重载（Overload）
发生时机运行时（动态绑定）编译时（静态绑定）
范围父子类之间同一类中
方法名相同相同
参数列表相同必须不同
返回类型相同或协变（子类型）无要求
访问修饰符≥ 父类无要求
异常不能 throws 更宽异常无要求
⚠️ private/static/final 方法不能被重写；static 方法可被子类"隐藏"（不是多态）。

4. 内部类

类型特点典型用途
成员内部类可访问外部类所有成员，需要外部类实例与外部类紧密耦合的逻辑
静态内部类不依赖外部类实例，只能访问外部类静态成员Builder 模式、工具类
局部内部类定义在方法内，作用域为方法较少使用
匿名内部类无类名，实现接口或继承类，JDK8 后常用 Lambda 替代事件监听、Runnable
// 静态内部类（推荐）—— 不会持有外部类引用，避免内存泄漏
class Outer {
    static class Builder {
        private String name;
        Builder name(String n){ this.name=n; return this; }
        Outer build(){ return new Outer(); }
    }
}
// 使用
Outer obj = new Outer.Builder().name("test").build();

5. 关键字详解

static

  • 静态变量：类级别共享，存放在方法区（JDK8 前 PermGen，JDK8 后 Metaspace）
  • 静态方法：不能访问实例变量/方法，不能使用 this/super
  • 静态代码块：类加载时执行一次，执行顺序：静态块 → 实例块 → 构造器
  • 静态内部类：见上

final

  • final 变量：基本类型值不可变；引用类型引用不可变（对象内容可变）
  • final 方法：不可被子类重写（但可重载）
  • final 类：不可被继承（如 String、Integer）
💡 final + volatile：final 字段在构造器中写入后对其他线程立即可见（禁止重排序）。

this vs super

方法调用本类方法调用父类被重写的方法
限制this()/super() 必须在构造器第一行，二选一同左

6. Object 核心方法

方法说明注意点
equals()默认比较引用，需重写比较内容重写 equals 必须重写 hashCode
hashCode()返回对象哈希值equals 相等 → hashCode 必须相等

// equals/hashCode 契约示例
@Override public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof User)) return false;
    User u = (User) o;
    return Objects.equals(id, u.id);
}
@Override public int hashCode() {
    return Objects.hash(id);  // 与 equals 一致
}

7. String 不可变性

为什么 String 不可变？

  • 内部 char[]（JDK 9 后 byte[]）被 private final 修饰
  • 没有暴露修改数组内容的方法
  • 类本身是 final，防止子类破坏不变性

不可变的好处

  • 线程安全：不可变对象天然线程安全
  • 字符串常量池：共享字面量，节省内存
  • 哈希值缓存：hashCode 只计算一次，HashMap key 性能好
  • 安全性：网络连接、类加载路径不会被修改

String s1 = "hello";           // 字符串常量池
String s2 = "hello";           // 复用常量池
String s3 = new String("hello"); // 堆上新建

s1 == s2;    // true（同一常量池对象）
s1 == s3;    // false（不同对象）
s1.equals(s3); // true（内容相同）
s3.intern() == s1; // true（intern 返回常量池引用）
