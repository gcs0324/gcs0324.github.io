1. Lambda 表达式 JDK 8

Lambda 是函数式接口（只有一个抽象方法的接口）的简洁写法，本质是匿名内部类的语法糖（字节码用 invokedynamic 实现）。

// 函数式接口写法演进
Runnable r1 = new Runnable() { public void run() { System.out.println("hi"); } };
Runnable r2 = () -> System.out.println("hi");  // Lambda

// 四大函数式接口
Function<T,R>    apply(T t):R      // 转换
Predicate<T>     test(T t):boolean // 判断
Consumer<T>      accept(T t):void  // 消费
Supplier<T>      get():T           // 生产

// 方法引用（4种）
obj::instanceMethod    // 实例方法引用
ClassName::staticMethod // 静态方法引用
ClassName::instanceMethod // 任意对象实例方法引用
ClassName::new          // 构造器引用
💡 Lambda 捕获的外部变量必须是 effectively final（不需要显式 final 关键字，但不能被修改）。

2. Stream API JDK 8

Stream 是数据管道，支持链式操作。分为中间操作（惰性求值）和终结操作（触发计算）。

类型方法说明
中间操作（惰性）filter(Predicate)过滤
map(Function)转换元素类型
flatMap(Function)扁平化（List<List> → List）
sorted() / sorted(Comparator)排序
distinct()去重（依赖 equals/hashCode）
limit(n) / skip(n)截取 / 跳过
终结操作（触发计算）collect(Collector)收集到集合
forEach(Consumer)遍历
count()计数
reduce()规约（求和/乘积）
findFirst() / findAny()查找
anyMatch/allMatch/noneMatch匹配判断
// 实战：统计每个部门的员工数，按人数降序
Map<String, Long> result = employees.stream()
    .filter(e -> e.getSalary() > 5000)
    .collect(Collectors.groupingBy(
        Employee::getDept,
        Collectors.counting()
    ));

// 并行流（使用 ForkJoinPool.commonPool）
long count = list.parallelStream()
    .filter(n -> n % 2 == 0)
    .count();
// 注意：并行流并不一定比顺序流快，数据量小时反而有线程开销
⚠️ 同一个 Stream 只能被消费一次，重复使用会抛 IllegalStateException。

3. Optional JDK 8

显式表达"可能为 null"的容器，避免 NPE，但不是银弹——不应用于方法参数、字段。

// 创建
Optional.of(value)        // value 不能为 null
Optional.ofNullable(v)    // v 可为 null
Optional.empty()

// 消费
opt.isPresent()           // 不推荐，等同于 if != null
opt.ifPresent(Consumer)   // ✅
opt.get()                 // 若 empty 抛 NoSuchElementException

// 转换
opt.map(Function)         // 转换，若 empty 返回 empty
opt.flatMap(Function)     // 返回 Optional<T> 的 map

// 默认值
opt.orElse(defaultVal)           // 总是计算 defaultVal
opt.orElseGet(Supplier)          // 惰性计算（推荐）
opt.orElseThrow(Supplier)        // 抛异常

// 链式避免 NPE（替代多层 if null）
String city = Optional.ofNullable(user)
    .map(User::getAddress)
    .map(Address::getCity)
    .orElse("unknown");

4. 新时间 API JDK 8

java.time 包（Joda-Time 思想）：不可变线程安全，替代 Date/Calendar。

类说明示例
LocalDate只有日期，无时间LocalDate.now(), of(2024,1,1)
LocalTime只有时间，无日期LocalTime.of(10,30,0)
LocalDateTime日期+时间，无时区LocalDateTime.now()
ZonedDateTime带时区ZonedDateTime.now(ZoneId.of("Asia/Shanghai"))
Instant时间戳（纳秒精度）Instant.now()
Duration时间段（秒/纳秒）Duration.between(t1, t2)
Period日期段（年/月/日）Period.between(d1, d2)
DateTimeFormatter格式化（线程安全）DateTimeFormatter.ofPattern("yyyy-MM-dd")
LocalDate today = LocalDate.now();
LocalDate next = today.plusDays(30).with(TemporalAdjusters.nextOrSame(DayOfWeek.MONDAY));

DateTimeFormatter fmt = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String s = LocalDateTime.now().format(fmt);
LocalDateTime dt = LocalDateTime.parse("2024-01-01 10:00:00", fmt);

5. 接口新特性

  • default 方法（JDK 8）：接口可有具体实现，解决接口演进时不破坏已有实现的问题
  • static 方法（JDK 8）：接口工厂方法
  • private 方法（JDK 9）：default 方法的内部复用
⚠️ 多接口 default 方法冲突时，实现类必须显式重写；子接口的 default 方法优先于父接口。

    """;

    // 阻塞 IO 不再占用平台线程，可创建百万级虚拟线程
});
