1. 泛型基础

泛型（Generics）在编译期检查类型，避免运行时 ClassCastException，提高代码复用性。

// 泛型类
class Box<T> {
    private T value;
    public T get() { return value; }
    public void set(T v) { this.value = v; }
}

// 泛型方法
public <T> List<T> asList(T... items) {
    return Arrays.asList(items);
}

// 有界类型参数
<T extends Comparable<T>>  // 上界，T 必须实现 Comparable
<T extends Number & Serializable>  // 多边界（类在前，接口在后）

2. 类型擦除

Java 泛型是"伪泛型"：编译后类型信息被擦除，运行时只有原始类型（Raw Type）。编译器插入强制类型转换保证类型安全。

// 编译前
List<String> list = new ArrayList<>();
String s = list.get(0);

// 编译后（字节码）
List list = new ArrayList();
String s = (String) list.get(0);  // 编译器自动插入强转

类型擦除的限制

  • 不能 new T()（运行时不知道 T 的具体类型）
  • 不能 new T[]（泛型数组创建禁止）
  • 不能 instanceof List<String>（只能 instanceof List）
  • 静态成员不能使用类泛型参数
  • 泛型类不能 extends Exception（不能作为异常类型）

如何在运行时获取泛型类型？

// 通过匿名子类保留泛型信息（TypeToken 原理）
TypeReference<List<String>> ref = new TypeReference<List<String>>(){};
// 父类 getGenericSuperclass() 获取参数化类型
Type type = ref.getClass().getGenericSuperclass(); // ParameterizedType

3. 通配符

通配符语法读取写入适用
无界通配符List<?>Object❌ 只能 null不关心类型时
上界通配符List<? extends T>T 或子类❌生产者（读取数据）
下界通配符List<? super T>Object✅ T 或子类消费者（写入数据）
💡 PECS 原则：Producer Extends，Consumer Super。Collections.copy(dest, src) 中 src 用 extends（生产），dest 用 super（消费）。
// PECS 示例
public static <T> void copy(List<? super T> dest, List<? extends T> src) {
    for (T e : src) dest.add(e);
}

4. 反射 API

反射允许在运行时检查和操作类的结构（字段、方法、构造器），是框架的核心机制。

// 获取 Class 对象的三种方式
Class<?> c1 = String.class;           // 类字面量（编译时）
Class<?> c2 = "hello".getClass();     // 实例方法
Class<?> c3 = Class.forName("java.lang.String"); // 动态（类名字符串）

// 反射创建实例
Constructor<?> ctor = c3.getDeclaredConstructor(String.class);
ctor.setAccessible(true);  // 突破私有访问
Object obj = ctor.newInstance("hello");

// 反射调用方法
Method m = c3.getDeclaredMethod("substring", int.class, int.class);
m.setAccessible(true);
String result = (String) m.invoke(obj, 0, 3);

// 反射访问字段
Field f = c3.getDeclaredField("value");
f.setAccessible(true);
byte[] bytes = (byte[]) f.get(obj);
方法说明
getDeclaredMethods()本类声明的所有方法（含 private），不含继承
getMethods()public 方法，含继承的
getDeclaredFields()本类所有字段（含 private）
getFields()public 字段，含继承
⚠️ 反射性能较低（约慢 1-2 个数量级），需频繁调用时缓存 Method/Field 对象。JDK 9+ 模块系统对 setAccessible 有限制。

5. 动态代理

JDK 动态代理CGLIB 代理
原理实现目标接口，生成 $Proxy 类继承目标类，生成子类
要求目标必须实现接口目标类不能是 final
核心 APIProxy.newProxyInstance + InvocationHandlerEnhancer + MethodInterceptor
性能JDK 8 后优化，接近 CGLIB通常略快（直接字节码）
Spring 选择有接口时默认使用无接口 或 proxyTargetClass=true
// JDK 动态代理
UserService proxy = (UserService) Proxy.newProxyInstance(
    target.getClass().getClassLoader(),
    target.getClass().getInterfaces(),
    (proxyObj, method, args) -> {
        System.out.println("before: " + method.getName());
        Object result = method.invoke(target, args);
        System.out.println("after");
        return result;
    }
);

6. 注解

元注解

元注解说明常用值
@Target注解可应用的位置TYPE, METHOD, FIELD, PARAMETER...
@Retention注解保留阶段SOURCE（编译期）/ CLASS（字节码）/ RUNTIME（运行时）
@Documented生成到 JavaDoc-
@Inherited子类继承父类注解仅对类注解有效
@Repeatable允许同一元素多次使用JDK 8 新增
// 自定义注解
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface Log {
    String value() default "";  // 注解属性
    LogLevel level() default LogLevel.INFO;
}

// 运行时读取注解
Method m = obj.getClass().getMethod("doSomething");
if (m.isAnnotationPresent(Log.class)) {
    Log log = m.getAnnotation(Log.class);
    System.out.println("log value: " + log.value());
}

注解处理器（APT）

编译期处理 SOURCE/CLASS 级别注解，生成额外代码（如 Lombok、MapStruct）。实现 AbstractProcessor，在 process() 中生成源文件。
