ArrayList vs LinkedList

对比ArrayListLinkedList
底层结构动态数组（Object[]）双向链表（Node）

ArrayList 扩容机制

// 默认初始容量 10
private static final int DEFAULT_CAPACITY = 10;

// 扩容：新容量 = 旧容量 + 旧容量 >> 1（即 * 1.5）
int newCapacity = oldCapacity + (oldCapacity >> 1);
elementData = Arrays.copyOf(elementData, newCapacity);
💡 预估容量时使用 new ArrayList<>(capacity) 避免多次扩容，提高性能。

3. HashMap 原理

JDK 8 结构

数组 + 链表 + 红黑树。初始容量 16，负载因子 0.75，链表长度 ≥ 8 且数组容量 ≥ 64 时转红黑树，红黑树节点 ≤ 6 退化为链表。

put() 流程

1. 计算 key.hashCode()，扰动：hash = (h = key.hashCode()) ^ (h >>> 16)
2. 若 table 为 null 或长度为 0 → resize() 初始化
3. index = (n-1) & hash，若 table[index] 为 null → 直接插入
4. 若 table[index] 不为 null：
   a. key 相同（hash 相等 && equals） → 覆盖 value
   b. 节点为 TreeNode → 红黑树插入
   c. 否则链表尾插，插入后若链表长度 >= 8 → treeifyBin()
5. size > threshold(capacity * loadFactor) → resize()（2 倍扩容）
版本JDK 7JDK 8
数据结构数组 + 链表数组 + 链表 + 红黑树
链表插入头插法（多线程扩容可能死循环）尾插法
hash 计算4次扰动1次扰动（h ^ h>>>16）
扩容重新 hash 分配高位为 0 不动，高位为 1 移到 oldCap+原位置
⚠️ HashMap 非线程安全。多线程环境下使用 ConcurrentHashMap（JDK8 CAS + synchronized 对链表头/红黑树根节点加锁）。

为什么容量必须是 2 的幂？

索引计算用 (n-1) & hash 替代取模 hash % n，位运算更快；且 n 为 2 的幂时 n-1 全为 1，分布更均匀。

4. Set 与 TreeMap

HashSet

底层是 HashMap，key 存元素，value 存 PRESENT（静态 Object 占位符）。添加元素时调用 HashMap.put()，若已存在则返回 false。

LinkedHashMap / LinkedHashSet

在 HashMap 基础上维护双向链表记录插入顺序（或访问顺序，accessOrder=true 时 get 会将节点移到尾部，用于实现 LRU 缓存）。

// LRU 缓存（面试高频）
Map<K,V> lru = new LinkedHashMap<>(16, 0.75f, true) {
    protected boolean removeEldestEntry(Map.Entry<K,V> e) {
        return size() > MAX_SIZE;
    }
};

TreeMap

底层红黑树，按 key 自然顺序或 Comparator 排序。常用方法：firstKey()/lastKey()/headMap()/tailMap()/subMap()。

💡 TreeMap key 必须实现 Comparable 或提供 Comparator，否则 put 时 ClassCastException。

6. 迭代器 & fail-fast

fail-fast 机制

迭代器通过 modCount（结构修改次数）检测并发修改。每次迭代调用 next() 时检查 modCount == expectedModCount，不一致则抛出 ConcurrentModificationException。

// 错误：迭代时 list.remove() 修改了 modCount
for (String s : list) {
    if ("del".equals(s)) list.remove(s); // ❌ ConcurrentModificationException
}

// 正确方式1：Iterator.remove()
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    if ("del".equals(it.next())) it.remove(); // ✅ 同步 expectedModCount
}

// 正确方式2：removeIf（JDK 8）
list.removeIf(s -> "del".equals(s)); // ✅
💡 CopyOnWriteArrayList 是 fail-safe，迭代快照数组，不抛异常，但读取的可能是旧数据。
