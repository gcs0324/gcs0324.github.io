01IoC 核心概念
什么是 IoC（控制反转）

IoC（Inversion of Control）是一种设计思想，将对象的创建权和依赖管理权从代码本身转移给外部容器。传统方式：对象自己 new 依赖对象；IoC 方式：容器负责创建并注入依赖。

核心价值：解耦。上层模块不依赖下层模块的具体实现，依赖于抽象（接口），容器在运行时决定注入哪个实现。

BeanFactory vs ApplicationContext
维度BeanFactoryApplicationContext
定位IoC 容器顶层接口，基础功能BeanFactory 子接口，企业级功能
加载时机懒加载（getBean 时才实例化）预加载（启动时实例化所有单例）
功能扩展仅 Bean 管理+国际化 / +事件 / +AOP / +资源加载
使用场景内存敏感的轻量级场景绝大多数 Spring 应用
02依赖注入方式
三种注入方式对比
方式写法优缺点
构造器注入@Autowired 在构造器上✅ 依赖不可变，可保证必要依赖；❌ 参数过多时臃肿；Spring 官方推荐
Setter 注入@Autowired 在 setter 方法✅ 可选依赖灵活；❌ 依赖可变，可能被意外修改
字段注入@Autowired 直接在字段✅ 写法简洁；❌ 无法注入 final 字段，不利于单元测试，不推荐
最佳实践：必需依赖用构造器注入，可选依赖用 Setter 注入，避免使用字段注入。
03Bean 生命周期
完整生命周期 7 阶段
①
实例化（Instantiation）
容器通过反射调用构造器（或工厂方法）创建 Bean 的原始 Java 对象，属性值均为零值
②
属性填充（Populate）
依赖注入：填充 @Autowired、@Value、@Resource 等注解标注的属性；三级缓存解循环依赖发生在此阶段
③
Aware 回调
若 Bean 实现了 BeanNameAware → setBeanName()；BeanFactoryAware → setBeanFactory()；ApplicationContextAware → setApplicationContext()
④
BeanPostProcessor#before
调用所有注册的 BeanPostProcessor 的 postProcessBeforeInitialization() 方法，可在初始化前修改 Bean
⑤
初始化（Initialization）
顺序：① @PostConstruct 注解方法 → ② InitializingBean#afterPropertiesSet() → ③ 自定义 init-method
⑥
BeanPostProcessor#after ← AOP 代理在此生成
调用 postProcessAfterInitialization()；AbstractAutoProxyCreator 在此检查是否需要创建 AOP 代理，若需要则返回代理对象替换原始对象
⑦
销毁（Destruction）
容器关闭时：① @PreDestroy → ② DisposableBean#destroy() → ③ 自定义 destroy-method
04Bean 作用域
5 种作用域
作用域说明线程安全
singleton（默认）容器内唯一实例，随容器启动创建，随容器关闭销毁无状态则安全
prototype每次 getBean() 创建新实例，容器不管理其销毁各自独立，安全
request每个 HTTP 请求创建新实例，请求结束销毁请求内安全
session每个 HTTP Session 创建新实例，Session 超时销毁单用户安全
applicationServletContext 生命周期内唯一实例同 singleton
注意：在 singleton Bean 中注入 prototype Bean 时，直接 @Autowired 只会注入一次，之后每次用的都是同一个 prototype 实例。解决方案：通过 ApplicationContext#getBean() 或 @Lookup 注解每次获取新实例。
05循环依赖与三级缓存
三级缓存数据结构
缓存Map 名称存储内容用途
一级缓存singletonObjects完整 Bean（初始化完成）正常的单例对象池
二级缓存earlySingletonObjects早期暴露的 Bean（可能是代理）防止同一 Bean 被多次代理
三级缓存singletonFactoriesObjectFactory Lambda按需生成（可能被 AOP 代理的）早期 Bean

解决循环依赖的流程：A 创建时先把自己的 ObjectFactory 放入三级缓存 → 填充属性时需要 B → 创建 B → B 填充属性需要 A → 从三级缓存获取 A 的 ObjectFactory，调用生成早期 A（或 A 的代理）放入二级缓存 → B 创建完成 → A 继续完成初始化 → A 的最终对象（代理或原始）进入一级缓存。

哪些循环依赖无法解决？
① 构造器注入的循环依赖（实例化时就需要依赖，三级缓存未建立）
② prototype 作用域的循环依赖（容器不缓存 prototype Bean）
06容器启动 — refresh() 核心流程
AbstractApplicationContext#refresh() 12 步
1
prepareRefresh()
记录启动时间，设置容器状态，校验必要的环境属性
2
obtainFreshBeanFactory()
创建 DefaultListableBeanFactory，解析 XML/注解，加载所有 BeanDefinition
3
prepareBeanFactory()
配置类加载器，注册内置 BeanPostProcessor（如 ApplicationContextAwareProcessor）
4
postProcessBeanFactory()
子类扩展钩子，Web 容器在此注册 Servlet 相关作用域
5 ★
invokeBeanFactoryPostProcessors()
执行所有 BeanFactoryPostProcessor；ConfigurationClassPostProcessor 在此解析 @Configuration、@ComponentScan、@Import、@Bean
6 ★
registerBeanPostProcessors()
注册所有 BeanPostProcessor；AOP 的 AnnotationAwareAspectJAutoProxyCreator 在此注册
7-11
消息源 / 事件广播 / 子类扩展 / 监听器注册
initMessageSource / initApplicationEventMulticaster / onRefresh（Web 容器在此创建内嵌 Tomcat）/ registerListeners
12 ★
finishBeanFactoryInitialization()
实例化所有非懒加载的单例 Bean，触发完整 Bean 生命周期。这是容器启动最耗时的步骤
07注解驱动
常用注解速查
注解作用说明
@Component标记为 Spring 组件通用；@Service / @Repository / @Controller 是其语义化别名
@Autowired依赖注入按类型注入，多候选时按字段名 / @Qualifier 区分
@Resource依赖注入（JSR-250）按名称注入，name 属性指定 Bean 名
@Value注入配置值@Value("${key}") 或 @Value("#{expression}")
@Configuration声明配置类Full 模式（CGLIB 代理），保证 @Bean 方法单例语义
@Bean声明 Bean配合 @Configuration 使用，方法返回值注册为 Bean
@Conditional条件化注册@ConditionalOnClass / @ConditionalOnMissingBean 等
@Lazy懒加载延迟到第一次使用时才创建
@Primary首选候选多个同类型 Bean 时，标注此注解的优先被注入
@Qualifier精确指定按名称区分多个同类型 Bean
08FactoryBean
FactoryBean 接口

实现 FactoryBean<T> 接口可以控制 Bean 的创建逻辑，容器调用 getObject() 获取实际注册的对象：

public class MyFactoryBean implements FactoryBean<MyService> {
    @Override
    public MyService getObject() {
        // 复杂的创建逻辑，如动态代理
        return (MyService) Proxy.newProxyInstance(...);
    }
    @Override
    public Class<?> getObjectType() { return MyService.class; }
    @Override
    public boolean isSingleton() { return true; }
}

// 注入的是 getObject() 返回的 MyService（代理对象）
@Autowired MyService myService;

// 加 & 前缀获取 FactoryBean 本身
@Autowired @Qualifier("&myFactoryBean") MyFactoryBean fb;

典型应用：MyBatis MapperFactoryBean、Spring AOP ProxyFactoryBean、Dubbo 服务代理。
