1. 观察者模式 Observer

意图：定义对象间的一对多依赖，当一个对象状态变化时，所有依赖者自动通知更新。也称发布-订阅。

// Java 内置观察者（已过时，了解即可）
class EventPublisher {
    private List<EventListener> listeners = new ArrayList<>();
    public void addListener(EventListener l) { listeners.add(l); }
    public void publish(Event event) {
        listeners.forEach(l -> l.onEvent(event));
    }
}

// Spring ApplicationEvent（推荐）
@Component
public class OrderCreatedListener implements ApplicationListener<OrderCreatedEvent> {
    public void onApplicationEvent(OrderCreatedEvent event) {
        // 异步处理：发送通知、扣减库存等
    }
}
// 发布事件
@Autowired ApplicationEventPublisher publisher;
publisher.publishEvent(new OrderCreatedEvent(this, order));

// 更简洁的 @EventListener（Spring 4.2+）
@EventListener
@Async  // 异步处理
public void handleOrderCreated(OrderCreatedEvent event) { ... }
💡 观察者 vs 发布-订阅：观察者直接知道被观察者；发布-订阅通过事件总线解耦，二者不直接引用（如 MQ）。

2. 策略模式 Strategy

意图：定义算法族，封装每个算法，使它们可互换。消除大量 if-else，开闭原则（扩展开放，修改关闭）。

// 场景：不同支付方式
interface PayStrategy {
    PayResult pay(PayRequest req);
}
@Component("alipay")   class AliPayStrategy implements PayStrategy { ... }
@Component("wechat")   class WechatPayStrategy implements PayStrategy { ... }
@Component("credit")   class CreditCardStrategy implements PayStrategy { ... }

// Context：根据参数选择策略（替代 if-else）
@Service
public class PayService {
    @Autowired
    private Map<String, PayStrategy> strategyMap;  // Spring 自动注入所有实现

    public PayResult pay(String type, PayRequest req) {
        PayStrategy strategy = strategyMap.get(type);
        if (strategy == null) throw new UnsupportedPayTypeException(type);
        return strategy.pay(req);
    }
}
// 新增支付方式只需添加新实现类 + @Component，无需改动 PayService
💡 策略模式是消除 if-else/switch 的利器。Spring 利用 Map 注入（Map<String, XxxStrategy>）实现策略工厂，极为优雅。

3. 责任链模式 Chain of Responsibility

意图：将请求沿处理者链传递，每个处理者决定处理或传递给下一个，解耦请求发送者与接收者。

// 订单审批链
abstract class Approver {
    protected Approver next;
    public void setNext(Approver next) { this.next = next; }
    abstract void approve(Order order);
}
class TeamLeader extends Approver {
    void approve(Order order) {
        if (order.getAmount() < 1000) {
            System.out.println("组长审批通过");
        } else if (next != null) {
            next.approve(order);  // 传递给下一个
        }
    }
}
class Manager extends Approver {
    void approve(Order order) {
        if (order.getAmount() < 10000) System.out.println("经理审批通过");
        else if (next != null) next.approve(order);
    }
}
// 构建链
TeamLeader leader = new TeamLeader();
Manager manager = new Manager();
leader.setNext(manager);
leader.approve(order);

Spring 体现：Servlet Filter 链（doFilter→chain.doFilter()）、Spring Security FilterChain、Dubbo Filter 链、Netty ChannelPipeline

4. 模板方法模式 Template Method

意图：在父类定义算法骨架（模板），将某些步骤延迟到子类实现，子类不改变算法结构只改变某些步骤。

// 父类定义模板
abstract class DataProcessor {
    // 模板方法（final 防止子类修改流程）
    public final void process() {
        readData();      // 抽象方法，子类实现
        processData();   // 抽象方法
        writeResult();   // 钩子方法（有默认实现）
        if (needLog()) logResult(); // 钩子控制流程
    }
    protected abstract void readData();
    protected abstract void processData();
    protected void writeResult() { /* 默认写到控制台 */ }
    protected boolean needLog() { return true; }  // 钩子方法
}
class CsvProcessor extends DataProcessor {
    protected void readData() { /* 读 CSV */ }
    protected void processData() { /* 处理 CSV */ }
}
class ExcelProcessor extends DataProcessor {
    protected void readData() { /* 读 Excel */ }
    protected void processData() { /* 处理 Excel */ }
    protected boolean needLog() { return false; }  // 覆盖钩子
}

Spring 体现：AbstractBeanFactory.getBean()、JdbcTemplate、RestTemplate、AbstractApplicationContext.refresh()

5. 命令模式 Command

意图：将请求封装为对象，支持撤销/重做、队列执行、日志记录。解耦调用者与执行者。

// 命令接口
interface Command {
    void execute();
    void undo();
}
class InsertTextCommand implements Command {
    private TextEditor editor;
    private String text;
    private int position;
    public void execute() { editor.insert(position, text); }
    public void undo() { editor.delete(position, text.length()); }
}

// 调用者（不知道具体执行逻辑）
class CommandManager {
    private Deque<Command> history = new ArrayDeque<>();
    public void execute(Command cmd) {
        cmd.execute();
        history.push(cmd);
    }
    public void undo() {
        if (!history.isEmpty()) history.pop().undo();
    }
}
// 应用：文本编辑器 Ctrl+Z，数据库事务日志，MQ 消息（消息即命令）

6. 状态模式 State

意图：允许对象在内部状态改变时改变行为，消除大量状态判断的 if-else。

// 订单状态机
interface OrderState {
    void pay(Order order);
    void ship(Order order);
    void complete(Order order);
    void cancel(Order order);
}
class PendingState implements OrderState {
    public void pay(Order order) {
        System.out.println("支付成功");
        order.setState(new PaidState());  // 状态转换
    }
    public void ship(Order order) { throw new IllegalStateException("未支付不能发货"); }
    public void cancel(Order order) { order.setState(new CancelledState()); }
    public void complete(Order order) { throw new IllegalStateException(); }
}
class Order {
    private OrderState state = new PendingState();
    public void setState(OrderState s) { this.state = s; }
    public void pay() { state.pay(this); }
    public void ship() { state.ship(this); }
}

应用：订单状态机、工作流引擎、TCP 连接状态、自动贩卖机。Spring StateMachine 框架就是状态模式的企业级实现。
