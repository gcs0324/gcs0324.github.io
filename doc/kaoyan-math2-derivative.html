§2 可直接套用的解题步骤

不可导点五步判定

目标在函数连续的基础上，找出左右导数不相等或导数不存在的点。

1找可疑点
→
2先判连续
→
3算左右导数
→
4判断类型
1

第一步：找可疑点

普通光滑区间通常可直接用求导公式，真正需要单独检查的是结构发生变化的位置：

  • 分段函数的分界点
  • 绝对值内部等于 0 的点
  • 根式内部等于 0 的点
  • 图像的尖点、角点、竖直切线
  • 函数的间断点
可导 ⇒ 连续

所以间断点一定不可导，可以先直接列入不可导点。

2

第二步：先判断是否连续

对每个可疑点 x₀，先比较左极限、右极限和函数值：

limx→x₀⁻f(x) = limx→x₀⁺f(x) = f(x₀)

若这个等式不成立，函数在 x₀ 不连续，也就不可能可导；不需要再算左右导数。

3

第三步：计算左右导数

函数连续后，再回到导数定义。分段点不能只把 x₀ 代入两边的导函数公式。

f′₋(x₀)=limx→x₀⁻ [f(x)-f(x₀)]/(x-x₀)
f′₊(x₀)=limx→x₀⁺ [f(x)-f(x₀)]/(x-x₀)

结果检查左右导数都存在、有限且相等，函数才在 x₀ 可导。

4

第四步：判断不可导类型

不可导不只一种表现。根据两侧割线斜率的极限，可以进一步判断图像形状：

角点

左右导数都有限，但数值不相等。

尖点

左右斜率分别趋于 +∞ 和 -∞，方向相反。

竖直切线

两侧斜率趋于同一个无穷方向，切线竖直。

其他不可导

函数不连续，或至少一个单侧导数不存在。

完整例题

判断 f(x)=|x| 在 x=0 处是否可导

1

绝对值内部 x 在 0 处变号，因此 x=0 是可疑点；同时 lim[x→0]|x|=0=f(0)，函数在这里连续。

2

x<0 时 |x|=-x，所以左导数为：

f′₋(0)=limx→0⁻ |x|/x = limx→0⁻(-x/x) = -1
3

x>0 时 |x|=x，所以右导数为：

f′₊(0)=limx→0⁺ |x|/x = 1
结论：左右导数 -1 与 1 不相等，所以 x=0 不可导；图像在此处形成角点。

易错点连续只是可导的必要条件，不是充分条件；分段点要用单侧导数定义，不能只比较两侧导函数的形式。

考试速记找可疑点 → 先判连续 → 算左右导数 → 判断不可导类型

单调、极值与最值

目标用一阶导数符号表同时解决单调区间、局部极值和闭区间最值。

1写定义域
→
2找临界点
→
3列导数符号表
→
4比较候选值

识别信号题目要求单调区间、极值点、最大最小值，或需证明函数值不等式。

临界点

包括 f′=0 的点，也包括函数有定义但导数不存在的点。

f′(x)=0 或不存在
单调性

每个分区间内判断 f′ 的正负，而不是只看临界点本身。

f′>0 增；f′<0 减
局部极值

导数正变负是极大，负变正是极小；不变号就没有极值。

+→- 极大；-→+ 极小
绝对最值

闭区间上必须把临界点与两个端点的函数值一起比较。

候选点 + 端点
1

第一步：写定义域和研究区间

先排除函数无定义处。闭区间题把左右端点先记入最值候选，开区间则要关注端点极限。

2

第二步：求导并找临界点

解 f′(x)=0，同时列出 f 存在而 f′ 不存在的点；这些点共同把定义域切成若干区间。

3

第三步：制作导数符号表

在每个区间选测试点或因式判断符号，写清函数递增、递减以及临界点两侧的符号变化。

4

第四步：判极值并比较最值

先按符号变化判局部极值；若求闭区间最大最小值，再计算所有临界点与端点的函数值后比较。

完整例题

求 f(x)=x³-3x 在 [-2,2] 上的单调性和最值

1

求导并分解：

f′(x)=3x²-3=3(x-1)(x+1)
2

临界点为 x=-1、1。导数在 (-2,-1) 为正，在 (-1,1) 为负，在 (1,2) 为正。

+　|x=-1|　-　|x=1|　+
3

所以函数先增、后减、再增；x=-1 为极大点，x=1 为极小点。

4

比较端点和临界点：

f(-2)=-2，f(-1)=2，f(1)=-2，f(2)=2
最大值 2，在 x=-1、2 取得；最小值 -2，在 x=-2、1 取得。

结果检查把临界点和端点代回原函数，并用导数符号变化核对结论。

易错点认为 f′=0 就一定有极值；漏掉不可导点；闭区间最值忘记端点。

考试速记定义域 → f′=0 与不可导点 → 导数符号表 → 极值看变号 → 最值加端点

凹凸、拐点与渐近线

目标把二阶导数、定义域边界和无穷远极限合在一张图中，判断凹凸、拐点与渐近线。

1写定义域
→
2判 f″ 符号
→
3确认拐点
→
4计算渐近线

识别信号题目要求作图特征、凹凸区间、拐点，或水平、铅直、斜渐近线。

凹凸区间

按教材约定由 f″ 的正负判断，必须写在定义域的连续区间上。

f″ 正负分区
拐点

候选点必须在曲线上，并且左右凹凸性确实改变。

f″=0 只是候选
铅直渐近线

在定义域边界算单侧极限，至少一侧趋于无穷才成立。

x=a
水平或斜渐近线

先查有限极限；没有水平线时，再算斜率 k 和截距 b。

y=kx+b
1

第一步：先写定义域

函数无定义点会切断凹凸区间，也可能产生铅直渐近线；它本身不能作为拐点。

2

第二步：用 f″ 制作凹凸表

求 f″，把 f″=0 或不存在的点与定义域边界一起排序，在每个区间判断二阶导符号。

3

第三步：确认真正的拐点

只有候选点属于函数图像，且穿过该点后 f″ 变号，才能写成拐点 (x₀,f(x₀))。

4

第四步：依次检查三类渐近线

边界处趋于无穷得到 x=a；x→±∞ 的函数极限有限得到水平线；否则计算 k=lim f/x、b=lim(f-kx)。

完整例题

分析 f(x)=x+1/x 的凹凸、拐点和渐近线

1

定义域为 x≠0。求二阶导：

f″(x)=2/x³
2

x<0 时 f″<0，x>0 时 f″>0。凹凸性在 0 两侧改变，但 x=0 不在定义域。

3

因此 0 不是拐点；再看边界：

lim[x→0⁺]f(x)=+∞，lim[x→0⁻]f(x)=-∞
4

无穷远处计算斜渐近线：

k=lim f/x=1，b=lim(f-x)=lim 1/x=0
x=0 是铅直渐近线，y=x 是斜渐近线；函数没有拐点。

结果检查用函数的大致走势反查；斜渐近线还应满足 lim[f(x)-(kx+b)]=0。

易错点把 f″=0 直接当拐点；函数无定义就直接写铅直渐近线；同一方向同时写水平与斜渐近线。

考试速记f″=0 只找候选 → 必须变号且点在图上 → 边界查铅直 → 无穷远查水平/斜线
§3 典型题怎么一步步做
教程例题 · 分段点按定义求导
f(x)=|x|，判断 x=0 是否可导。
1连续只能作为可导的必要条件，不能直接推出可导。
2右导数 lim[h→0⁺]|h|/h=1；左导数 lim[h→0⁻]|h|/h=-1。
3左右导数不等，所以 x=0 不可导。
不可导但连续；易错点是把连续当成可导。
教程例题 · 隐函数二阶导
x²+xy+y²=3，求 dy/dx。
1两边对 x 求导：2x+y+x y′+2y y′=0，其中 xy 用乘积法则。
2合并 y′ 项：(x+2y)y′=-(2x+y)。
3当 x+2y≠0 时，y′=-(2x+y)/(x+2y)；求二阶时需再对该关系求导。
y′=-(2x+y)/(x+2y)，分母为 0 的点需单独讨论切线。
教程例题 · 中值定理先核条件
证明正数 a
1令 f(x)=ln x，它在 [a,b] 连续、(a,b) 可导，可用 Lagrange 中值定理。
2存在 ξ∈(a,b)，使 ln b-ln a=(b-a)/ξ。
3因为 ξ>a，所以 1/ξ<1/a；乘以 b-a>0 得结论。
证明完成；若不写连续可导条件，解答题会丢步骤分。
教程例题 · 极值与最值要比较端点
求 f(x)=x³-3x 在 [-2,2] 的最大最小值。
1f′=3x²-3=3(x-1)(x+1)，临界点为 ±1。
2计算候选点：f(-2)=-2，f(-1)=2，f(1)=-2，f(2)=2。
3闭区间最值必须比较临界点和两个端点。
最大值 2，最小值 -2；不能只看导数为零的点。
考试型练习 · 考试型练习
求 f(x)=x+1/x（x>0）的最小值。
1f′=1-1/x²，唯一临界点 x=1；x<1 时导数负，x>1 时正。
2函数先减后增，故 x=1 为全局最小点，f(1)=2。
最小值 2；也可用 AM-GM 反查。
