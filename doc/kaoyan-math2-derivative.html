§1 方法选择主线
先求定义域→计算一阶/二阶导→临界点分区间→列符号表→回查端点与题设
可导 ⇒ 连续；极值必要条件 f′(x₀)=0 需要 x₀ 为内点且可导；拐点必须凹凸性改变
原则

先写适用条件和第一步，再计算。方法不满足条件时，即使最后数字碰巧正确也不算真正掌握。

§2 可直接套用的解题步骤

不可导点五步判定

识别信号分段点、绝对值内部为 0、根式定义域端点、尖点，以及函数本身不连续的点。

  1. 1从分段界点、绝对值零点和定义域边界中列出所有可疑点。
  2. 2先查连续性；若在 x₀ 不连续，则一定不可导，可以直接记录原因。
  3. 3对仍连续的点，用导数定义计算左导数 f′₋(x₀)。
  4. 4再用导数定义计算右导数 f′₊(x₀)。
  5. 5左右导数存在、有限且相等才可导；否则结合斜率表现判断角点、尖点或竖直切线。

结果检查用“可导必连续”反查；分段点不能只代入两侧导函数的端点值。

易错点把连续当成可导；未用单侧导数；看到斜率无穷就写导数存在。

单调、极值与最值

识别信号题目要求单调区间、极值点、最大最小值，或需证明函数值不等式。

  1. 1先写定义域和研究区间，闭区间问题把两个端点单独记为最值候选。
  2. 2求 f′(x)，列出 f′=0 的点以及 f′ 不存在但 f 存在的点。
  3. 3按这些点分区间，制作 f′ 的符号表，正号递增、负号递减。
  4. 4导数由正变负为极大，由负变正为极小；不变号则不是极值点。
  5. 5闭区间最值要把所有极值候选和端点函数值放在一起比较。

结果检查把临界点和端点代回原函数，并用导数符号变化核对结论。

易错点认为 f′=0 就一定有极值；漏掉不可导点；闭区间最值忘记端点。

凹凸、拐点与渐近线

识别信号题目要求作图特征、凹凸区间、拐点，或水平、铅直、斜渐近线。

  1. 1求 f″(x)，列出 f″=0 或 f″ 不存在但函数有定义的候选点。
  2. 2在候选点两侧判断 f″ 符号，按教材约定写出凹凸区间。
  3. 3只有凹凸性确实改变且点在曲线上，候选点才是拐点。
  4. 4在定义域边界查函数是否趋于无穷，以确定铅直渐近线。
  5. 5在 x→±∞ 时依次查水平渐近线；若无，再算 k=lim(f/x)、b=lim(f-kx) 判断斜渐近线。

结果检查用函数的大致走势反查；斜渐近线还应满足 lim[f(x)-(kx+b)]=0。

易错点把 f″=0 直接当拐点；函数无定义就直接写铅直渐近线；同一方向同时写水平与斜渐近线。

§3 典型题怎么一步步做
教程例题 · 分段点按定义求导
f(x)=|x|，判断 x=0 是否可导。
1连续只能作为可导的必要条件，不能直接推出可导。
2右导数 lim[h→0⁺]|h|/h=1；左导数 lim[h→0⁻]|h|/h=-1。
3左右导数不等，所以 x=0 不可导。
不可导但连续；易错点是把连续当成可导。
教程例题 · 隐函数二阶导
x²+xy+y²=3，求 dy/dx。
1两边对 x 求导：2x+y+x y′+2y y′=0，其中 xy 用乘积法则。
2合并 y′ 项：(x+2y)y′=-(2x+y)。
3当 x+2y≠0 时，y′=-(2x+y)/(x+2y)；求二阶时需再对该关系求导。
y′=-(2x+y)/(x+2y)，分母为 0 的点需单独讨论切线。
教程例题 · 中值定理先核条件
证明正数 a
1令 f(x)=ln x，它在 [a,b] 连续、(a,b) 可导，可用 Lagrange 中值定理。
2存在 ξ∈(a,b)，使 ln b-ln a=(b-a)/ξ。
3因为 ξ>a，所以 1/ξ<1/a；乘以 b-a>0 得结论。
证明完成；若不写连续可导条件，解答题会丢步骤分。
教程例题 · 极值与最值要比较端点
求 f(x)=x³-3x 在 [-2,2] 的最大最小值。
1f′=3x²-3=3(x-1)(x+1)，临界点为 ±1。
2计算候选点：f(-2)=-2，f(-1)=2，f(1)=-2，f(2)=2。
3闭区间最值必须比较临界点和两个端点。
最大值 2，最小值 -2；不能只看导数为零的点。
考试型练习 · 考试型练习
求 f(x)=x+1/x（x>0）的最小值。
1f′=1-1/x²，唯一临界点 x=1；x<1 时导数负，x>1 时正。
2函数先减后增，故 x=1 为全局最小点，f(1)=2。
最小值 2；也可用 AM-GM 反查。
