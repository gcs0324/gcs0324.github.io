MMDB 美团数据库高可用架构

美团自研 MySQL 改良方案，基于 DBProxy 代理层 + 主从复制 + 自动 Failover，实现秒级故障切换与读写分离。

美团技术 MySQL · 高可用

各层说明

01
应用层Business Service
业务服务直接连 DBProxy，不感知底层拓扑变化。主库切换时应用无需重启或修改配置。
02
DBProxy代理层
核心枢纽。负责读写分离（写打主库、读打从库）、连接池复用、健康探测、自动路由。业务代码零改动。
03
主从节点Master / Slave
基于 MySQL 半同步复制（Semi-sync），保证主库故障时从库数据基本完整。多从库分摊读压力，支持横向扩展。
04
故障切换Failover
三步走：① HA Agent 心跳检测到主库不可达 → ② ZooKeeper 选出新主（避免脑裂）→ ③ VIP/DNS 漂移，流量秒级切换，应用几乎无感知。
05
监控平台DBA Platform
慢查询分析、容量规划、实时告警、自动扩容，支撑 DBA 全生命周期运维。
06
分库分表Sharding
单库达到容量瓶颈后，由 Sharding 中间件横向拆分，DBProxy 负责路由，上层完全无感知。
