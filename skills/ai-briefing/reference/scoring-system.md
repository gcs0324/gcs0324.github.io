# 评分体系详细说明

## 1. 重要性评分 (0-100)

### 计算公式

```
importance_score = (技术价值 + 创新性 + 实用价值 + 对研发工程师影响 + 半年影响力) * 2
```

### 评分维度（每个维度 0-10 分）

| 维度       | 说明            |
|----------|---------------|
| 技术价值     | 是否有真实的技术突破或改进 |
| 创新性      | 是否有新的思路、方法或架构 |
| 实用价值     | 开发者能否直接使用或学习  |
| 对研发工程师影响 | 对日常开发工作的影响程度  |
| 半年影响力    | 6个月后是否仍然重要    |

### 打分锚点（保证跨运行一致性，打分时对照取最接近档位）

| 维度 | 0 分 | 5 分 | 10 分 |
|------|------|------|-------|
| 技术价值 | 无技术内容的营销稿/口号 | 对已有方法的可验证增量改进 | 可复现的范式级突破，附代码或论文 |
| 创新性 | 完全复刻已有方案 | 已有思路在新场景的组合应用 | 提出此前不存在的新方法/新架构 |
| 实用价值 | 无法获取或使用（闭源无API无文档） | 有文档可上手，但集成成本较高 | 开箱即用，当天可集成进现有工作流 |
| 对研发工程师影响 | 与日常开发无关 | 改变某个细分环节的做法（如测试、CR） | 改变核心开发方式（如编码、架构设计） |
| 半年影响力 | 一周后无人再提的热点 | 所在细分方向会持续，标的本身存疑 | 大概率成为6个月后的基础设施或必备技能 |

### 评分阈值

| 分数    | 处理方式    |
|-------|---------|
| < 40  | 删除，不保留  |
| 40-59 | 保留，简要分析 |
| 60+   | 深度分析    |

## 2. Signal Score (0-100)

### 计算公式

公式输入与 Phase 1 实际采集的三个数据源一一对应，不引入未采集的数据：

```
Signal Score = GitHub热度 * 0.4 + 新闻热度 * 0.2 + 论文增长率 * 0.3 + 持续时间 * 0.1
```

### 输入定义（每项 0-100）

| 输入 | 数据来源 | 取值依据 |
|------|---------|---------|
| GitHub热度 | GitHub Trending | 相关项目近7天 Star 增速与上榜频次 |
| 新闻热度 | 猫猫新闻 | 该概念近7天在新闻条目中的提及频次 |
| 论文增长率 | Arxiv | 近30天相关论文出现数量及趋势 |
| 持续时间 | 全部源 | 信号连续出现的周数（1周=30，2-3周=60，4周+=90） |

### 缺失输入规则

- 某项输入本次未采集到（来源失败或无相关数据）时：将其权重按比例分摊到其余有效输入，重新归一化后计算。
- 在该信号条目处标注「基于 N/3 项数据源输入」。
- **禁止**为缺失输入估值、引用未采集来源（如 HN/Reddit/Twitter 讨论度）作为打分依据。

### 信号等级

| 分数    | 等级    | 说明   |
|-------|-------|------|
| 0-30  | 噪音    | 可忽略  |
| 30-50 | 弱信号   | 值得关注 |
| 50-70 | 值得关注  | 建议跟踪 |
| 70-90 | 高价值趋势 | 重点投入 |
| 90+   | 下一代方向 | 必须跟进 |

## 3. Developer ROI Score (0-100)

### 评估标准

所有内容必须回答：**这个内容是否能够提升研发工程师未来6-12个月的竞争力？**

### 高权重方向（自动加分）

- Agent Engineering
- Context Engineering
- MCP (Model Context Protocol)
- Coding Agent
- AI开发工具
- AI工程化
- 自动化开发
- Agent架构设计

### 降权方向（自动减分）

- 模型营销新闻
- 无技术细节发布会
- 纯资本市场新闻
- 纯融资新闻

## 4. GitHub项目评估

### 评分指标

| 指标     | 范围   | 说明        |
|--------|------|-----------|
| 学习价值评分 | 1-10 | 从该项目能学到多少 |
| 推荐指数   | 1-10 | 是否值得投入时间  |
| 是否立即关注 | 是/否  | 是否需要立即关注  |

### 评估维度

1. **项目定位** - 解决什么问题
2. **核心设计** - 技术架构分析
3. **同类对比** - 与AgentScope/LangGraph/CrewAI/AutoGen/OpenHands等对比
