#1DeusData/codebase-memory-mcp · 高性能代码智能 MCP Server

GitHub Trending · 本周 +7,560 ⭐ · 总 11,955 ⭐ · C · 重要性 92ROI 95

核心：把整个 codebase 用 tree-sitter 解析后写入一个持久化的知识图谱，毫秒级返回 caller/callee/impact/symbol 查询；以 MCP server 形态对外提供，被 Claude Code / Cursor / Cline 直接当作"代码检索后端"挂载。

为什么重要：Coding Agent 长期被 grep+Read 循环卡脖子——单次回答要做几十次文件读，token 和延迟双爆。把"代码索引"做成可被 Agent 调用的 MCP，本质上是给 Agent 加了"专用搜索引擎"。这是继 Skills 之后，第二个稳定的 Agent-OS 级原语。

同类对比：相比 Sourcegraph SCIP（重、需要服务端）和 LSP（每次需要打开文件），这个方案是 SQLite 本地化的——零基础设施成本是它一周冲到第一的根本原因。

#3📄 Plans Don't Persist: Why Context Management Is Load Bearing for LLM Agents

Arxiv · cs.AI · 重要性 87ROI 90

核心论点：当任务超出单次 context window 时，Agent 给自己写的 plan 会在 summary/compact 过程中悄无声息地丢失锚点（hidden constraints、subtle invariants）。论文给出一种把 plan 当成"一等公民持久状态"的方案，独立于对话历史存储与重注入。

为什么重要：这是 Context Engineering 第一次有论文级证据——"long-context 模型不能替代 memory 工程"。和 Claude Code 把 plan/task/memory 分层的产品设计一拍即合，下半年这个方向的论文会井喷。
