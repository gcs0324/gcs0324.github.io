#1 🥇 openai/codex-plugin-cc — Claude Code 调用 Codex 跨模型协作

82 本周最热 跨模型协作 GitHub · ⭐ 2,803/周

📊 深度分析

核心创新：OpenAI 官方发布 Codex CLI 的 Claude Code 插件，实现从 Claude Code 中直接调用 Codex 进行代码审查或任务委派。这是首次有两家头部 AI 公司的编码工具以"插件"形态互操作，标志着 Agent 工具链进入"跨模型协作"时代。

技术意义：不再局限于单模型 Agent，而是让不同模型各司其职——Claude Code 负责交互和编排，Codex 负责特定代码审查任务。这种"模型联邦"模式比单一 Agent 更灵活。

对研发工程师：如果你同时有 Claude Code 和 Codex 权限，现在可以让两者协作。这是 Agent 编排的实战案例，值得研究其架构。

#2 🥈 TencentCloud/CubeSandbox — AI Agent 即时安全沙箱

78 Agent 安全 基础设施 GitHub · ⭐ 2,490/周 · Rust

📊 深度分析

核心创新：腾讯云开源的轻量级 Agent 沙箱，主打"即时、并发、安全、轻量"。用 Rust 实现，启动速度极快，支持多 Agent 并发隔离执行。

技术意义：Agent 执行不可信代码（如生成的脚本、Shell 命令）是刚需。CubeSandbox 填补了"Agent 安全执行环境"这一空白，与 DesktopCommanderMCP 等工具形成互补——一个开放能力，一个兜底安全。

对研发工程师：如果你在开发 Agent 系统，沙箱是必备基础设施。CubeSandbox 的 Rust 实现值得学习其安全隔离设计。

#3 🥉 stablyai/orca — 并行 Agent 舰队管理器

78 多 Agent Agent 编排 GitHub · ⭐ 4,481/周 · TypeScript

📊 深度分析

对研发工程师：如果你经常同时处理多个编码任务，orca 可以让你并行跑多个 Agent。架构设计值得学习——如何管理多个 Agent 的生命周期、输出和资源。
