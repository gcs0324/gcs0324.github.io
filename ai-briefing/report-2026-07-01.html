本月：跟进 MCP 生态官方化进程

🧪 Section 6: 实验项目推荐

1. 为自己的项目搭一个代码智能 MCP Server

参考 codebase-memory-mcp 思路，为手头项目建一个轻量代码索引 MCP Server，接入 Claude Code 实测：相比现有查文件的方式，Agent 定位代码的准确率/耗时是否有明显改善。

2. 把团队开发流程写成 Agent Skill 包

参考 obra/superpowers 的 Skill 拆分粒度，为团队 1-2 个高频重复流程（如提测前检查清单、发版流程）写成可复用 Skill，周末即可验证效果。

3. 用 design.md 规范给前端项目写"Agent 可读"设计文档

选一个小型前端项目，按 design.md 格式补一份设计系统描述，对比编码 Agent 生成 UI 前后的风格一致性差异。
